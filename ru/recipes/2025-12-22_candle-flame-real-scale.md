# Пламя свечи в реальном масштабе (настройки nxExplosiaFX для мелкого масштаба)

- Источник: Top Tip Tuesday — Candle Simulation — https://www.youtube.com/watch?v=FPi_MrR0sGw (2025-12-22)
- Хост / поколение: C4D, Fused 2025.4 (nxExplosiaFX) + Redshift
- Задача: правдоподобное пламя свечи высотой ~15 cm с редкими порывами.

## Чек-лист для мелкого масштаба (дефолты настроены под большие сцены)
1. Ужмите домен вокруг фитиля; **Voxel Size 0.3 → 0.1**.
2. Источники: вся свеча, **Fuel 1.5 Weight by Tag** = polygon selection кончика фитиля. **Pressure 0** (в таком масштабе любое давление разрывает пламя).
3. Dynamics ▸ **Turbulence strength по умолчанию ~0.05**, масштаб длины поменьше.
4. Simulation ▸ Buoyancy: **Temperature Buoyancy ~0.5** (иначе получится огнемёт).
5. **Temperature Diffusion ~6** → мягкая, округлая форма пламени свечи.
6. Горение: Ignition Temperature 0, Burn Rate ↑, Gas Expansion 0, Smoke Production ~3. Smoke dissipation ↑. Пусть пламя будет чуть *великовато* — подрежете на рендере.
7. Порывы: привяжите силу турбулентности к **Document Time** (в секундах — кадры ÷ fps, например 100/30 = 3.33 до 400/30 = 13.3); нарисуйте на кривой горбы, оставьте небольшое базовое значение; общая сила ~0.09.
8. Redshift: температура → **Ramp** в материале пламени; сдвигайте чёрный узел внутрь, чтобы укоротить пламя, белый — чтобы удлинить.
