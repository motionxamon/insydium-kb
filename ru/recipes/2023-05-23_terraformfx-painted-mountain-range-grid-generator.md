# Горные хребты, нарисованные кистью (tfTerrain + tfNoise, умноженный на кисть TF Grid Generator)

- Источник: Top Tip Tuesday — TerraformFX Mountain Range — https://www.youtube.com/watch?v=szRmPLMOZq4 (2023-05-23)
- Хост / поколение: C4D; TerraformFX (без частиц); освещение во viewport из совета про световую схему от 2023-04-18
- Задача: точно управлять тем, где появляются детализированные пики и хребты, просто прорисовывая их.

## Исходная сцена
Стандартный **tfTerrain** из меню INSYDIUM; удалите фильтры по умолчанию, оставьте **tfNoise**. Цвет ландшафта выключен. Segments **500 → 1000** по обеим осям. Sun (infinite, с тенями) + синий слабый ambient-свет из совета про световую схему.

## Шаги
1. **tfNoise** ▸ Properties: тип турбулентности → **Stupl** (закрученная детализация). [▶ 1:10](https://youtu.be/szRmPLMOZq4?t=70)
2. tfTerrain ▸ Add Operator ▸ **TF Grid Generator** — контрольные точки, добавляющие высоту; сначала считается noise, затем сверху добавляется высота сетки. [▶ 1:36](https://youtu.be/szRmPLMOZq4?t=96)
3. Сбросьте сетку, поднимите число контрольных точек до **25 × 25** (X/Z), скройте точки. [▶ 2:15](https://youtu.be/szRmPLMOZq4?t=135)
4. Включите **Brush mode**: аэрограф **Elevate**, побольше силы, радиус поменьше; зажмите кнопку мыши, чтобы поднимать хребты. Случайные strength/intensity/scale у Elevate добавляют естественную неровность. [▶ 2:42](https://youtu.be/szRmPLMOZq4?t=162)
5. **Mode** операторa сетки: **Add → Multiply** — там, где сетка равна 0, noise гасится, и детализация появляется только там, где вы рисовали. Рисуйте/змейкой ведите хребты по вкусу (например, по референсу). [▶ 3:21](https://youtu.be/szRmPLMOZq4?t=201)
6. Ошибки исправляются процедурно: режим кисти **Smooth**, чтобы смягчить пик, потом обратно в Elevate. [▶ 4:04](https://youtu.be/szRmPLMOZq4?t=244)
7. Чтобы долины не были идеально плоскими: Elevate с **большим радиусом и очень маленькой силой**, слегка пройдитесь по плоским участкам. [▶ 4:36](https://youtu.be/szRmPLMOZq4?t=276)
8. Финальная детализация: segments ландшафта до **3000**.

## Подводные камни
В режиме Add нарисованные хребты просто ложатся поверх noise по всей площади; именно Multiply превращает кисть в маску.

## Как сейчас (новые инструменты)
Сегодня тот же workflow в TerraformFX; для детализации на рендере смотрите Advanced Terrain Shader / канал curvature из 2024.2 (рецепт 2025-02-04 — про displacement по карте высот).
