Older 2017–2022 videos (X-Particles 3.5/4, Premium/Maintenance Training) are summarised in `references/legacy-catalog/` instead of full recipes.

Processing order: **newest videos first** (2026 NeXus/Blender and beta previews → 2025.4 GPU EFX/FLIP era → 2023–2024 → early CPU tips). Each older recipe gets a "Modern equivalent" section pointing to the newest tool.

Built from the channel's subtitles (yt-dlp) and written as paraphrased build steps, never as transcripts. A Russian copy of the whole base lives in `insydium-kb-ru`.

Recipe file format (`recipes/YYYY-MM-DD_slug.md`):

```

## Scene tree
## Steps (with key values)
## Gotchas
## Modern equivalent (if the tip predates NeXus or 2026 changes)
```
