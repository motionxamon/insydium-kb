# Корни дерева двумя способами (слои веток Taiao Plant + гравитация; volume points Taiao Tree из эмиттера)

- Источник: Bite-Sized — Taiao Tree Roots — https://www.youtube.com/watch?v=B8RCRJy6cek (2025-10-02)
- Хост / поколение: C4D; **Taiao Plant** и **Taiao Tree** + обычный **xpEmitter** как источник точек; C4D Landscape + сферическое поле
- Задача: добавить дереву поверхностные корни — быстрые процедурные или «колонизирующие пространство» корни, расползающиеся по земле.

## Способ A — внутри Taiao Plant (проще всего)
1. Plant (изменённое дерево по умолчанию) ▸ Plant Layers ▸ выберите **Trunk** ▸ **add Branch** слой; выключите **Branch on End**.
2. Distribution: сдвиньте узлы сплайна так, чтобы ветки сидели внизу ствола; добавьте узел для объёма.
3. Main: добавьте длину + вариацию; угол слегка вниз.
4. Modifiers ▸ **Gravity**: поднимите силу, добавьте вариацию, подстройте weight → корни загибаются в землю. Увеличьте **profile width**.
5. Добавьте под ним второй слой Branch (вариация длины, угол, гравитация) для мелких корешков.
6. Если у Plant включены **Forces**, корни тоже качаются — поставьте слоям корней force **strength 0**.

## Способ B — Taiao Tree по рельефу
1. Добавьте C4D **Landscape** как землю.
2. **xpEmitter** ▸ Object: Landscape, **Polygon Area**; Emission **Shot** + **Simulate**, скорость 0. Object ▸ Falloff: **Spherical field**, масштабированное под зону корней.
3. Добавьте **Taiao Tree** ▸ **Volume Points**: киньте туда эмиттер → ветки растут по точкам частиц на земле. Поместите объект роста внутрь основания дерева.
4. Масштабируйте поле/эмиттер, чтобы менять разброс; поднимите **trunk thickness**, чтобы стыковалось с растением; дайте материал коры.
5. Настройте **resolution** (детализация) и **kill distance** (больше/меньше корней); добавьте Landscape как **Avoid object**, чтобы корни шли по поверхности (приблизительно).

## Как сейчас (новые инструменты)
Для выращенных сетей на GPU — **nxDendrite** (ветки/сеть) или **nxBioLogic** (2026.1 beta) могут создавать корнеподобный рост из частиц; Taiao остаётся путём для моделинга.
