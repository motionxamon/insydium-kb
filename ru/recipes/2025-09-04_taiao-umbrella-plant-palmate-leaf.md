# Процедурная шеффлера (пальчатый лопастной веер Taiao Leaf + Taiao Plant leaf-on-end, просвечивание в Redshift)

- Источник: INSYDIUM Official Training — Taiao Umbrella Plant — https://www.youtube.com/watch?v=ZyRwxTk3u80 (2025-09-04)
- Хост / поколение: C4D; Taiao Leaf (toLeaf) + Taiao Plant (toPlant); Redshift; без частиц
- Задача: комнатная шеффлера — тонкие изломанные стебли, каждый заканчивается поникшим веером из 8 листочков, в горшке.

## Лист (Taiao Leaf)
1. Main: сегменты **12 по длине / 4 по ширине**; настройте **profile spline** половины листа (добавьте точку посередине, полнее к кончику, острое основание).
2. **Thickness 5**; сплайн толщины толще в середине, сужается к обоим концам; **1 subdivision**.
3. Veins ▸ **Midvein**: сузьте её профиль; поднимите **Petiole offset**, чтобы получился черешок.
4. Модификаторы: **Fold** (сильный изгиб, меньше к кончику), **Furl** (провисание под гравитацией), Main ▸ petiole **Furl** для плавного изгиба черешка, **Turbulence** — настройте её **bias**, чтобы кончик и основание не ломались.
5. Main ▸ Leaf type **Lobed**; Lobing ▸ structure **Pinnate → Palmate** (веер). Короткая длина стебля, **leaf count 8**.
6. Orientation: **Angle**, чтобы раскрыть веер по кругу; **Twist**, чтобы наклонить листочки вверх, вариация для twist и angle.
7. Distribution: вариация размера; кривая **size bias** — маленькие листочки по краям, крупнее в середине.
8. Материалы: текстура листа на лист; ramp-материал на стебель + центральную жилку (ramps Redshift во viewport белые — видно только в рендере).

## Растение (Taiao Plant)
9. Trunk: высота **80 cm**, радиус **1**; Global ▸ segment resolution **1** (больше сегментов для ветвления). Модификаторы **Furl** (изгиб верха, низкий bias) + слабая **Turbulence** (bias подальше от основания); сужение через profile spline.
10. Add Part ▸ **Branch**: **Branch on End выкл.**, увеличьте угол ветвей, кривую распределения опустите; кривая длины ветвей короче к верху; вариация длины + угла; **Furl** с низким bias, затем снова увеличьте угол ветвей для компенсации.
11. На ветке Add Part ▸ **Leaf**: **count 0** при включённом **Leaf on End** → только лист на конце. Geometry mode **Custom**, перетащите лист; размер больше + вариация; Orientation **Y rotation** вниз, чтобы веер свисал. Число веток — по вкусу.
12. Для порядка положите лист дочерним под растение.

## Рендер (Redshift)
- Dome light с HDRI + sun & sky через окно ради теней.
- Листья: создайте материал типа с **Translucency/backlighting** (не стандартный); текстура → color correct (контраст) → более яркий color correct в translucency.
- Горшок: Maxon Noise + ramp с множеством узлов как bump.
