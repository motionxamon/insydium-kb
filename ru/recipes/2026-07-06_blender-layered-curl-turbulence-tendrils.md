# Усики из слоёной curl-турбулентности (слои nxTurbulence Curl + FBM + Voronoi, привязка к возрасту по слоям, ограничение nxSpeed, плавное появление через nxScale)

- Источник: NeXus for Blender Quick Guide — Turbulence Layers — https://www.youtube.com/watch?v=U937aVtRzMA (2026-07-06)
- Хост / поколение: Blender (NeXus for Blender, G3): nxEmitter, nxTurbulence (слои), nxColor, nxSpeed, nxScale
- Задача: аддитивные завитки из большого количества частиц, вылетающих из тонкого кольца, — всё на одном слоёном nxTurbulence.

## Исходная сцена
- Эмиттер **Disc ▸ Edge Only** (тонкая линия эмиссии — ключевой момент), направлен вверх; **100,000/s** (≈5× для рендера); время жизни 170 ±30.
- **nxColor**: Gradient by Speed, пресет градиента **Magma**.
- **nxSpeed**: дефолтный слой — incremental (+1.5 m/s за s) → поставьте increment **0**, ограничьте **max speed ~1**, чтобы силу турбулентности можно было сильно поднять без неконтролируемого ускорения.

## Шаги
1. **nxTurbulence**: удалите дефолтный Voronoi, добавьте слой **Curl**; strength сильно вверх, **scale ~600**, **frequency ~10%** (ниже = медленнее анимация, меньше дрожания).
2. Curl **Blend vs Add**: выключите Add; слайдер Blend смешивает скорость эмиттера (слева) с чистым curl (справа) — ~**0.38**, затем поднимите strength.
3. Ступеньки между кадрами (одинаковые скорости) → **substeps 4** в документе (по умолчанию 1).
4. Размер частиц в отображении 1 для детализации (в видео 2 из-за сжатия).
5. Добавьте слой **FBM** **над** curl (слои складываются сверху вниз, как в Photoshop). Очень низкая frequency → усики, похожие на прожилки; strength ~10. Оставьте режим смешивания **Normal** и смешивайте **слайдером силы слоя** (режимы смешивания перемножают скорости, и всё разлетается).
6. Добавьте сверху слой **Voronoi** для движения среднего масштаба: scale крупнее, низкая сила слоя, frequency чуть выше.
7. Привязка по слоям: Mapping ▸ **Age** → выберите слой (Curl / FBM / Voronoi) и параметр **Strength**; диапазон **5→15 кадров**, кривая от полной к низкой, конечный узел приподнят, чтобы немного FBM осталось (убирает пушистость края, сохраняя характер).
8. По желанию: Curl **Axis Direction Scale Z = 0** → плоские тонкие усики, которые потом раскрываются; **0.5** = сдержанные, томные 3D-завитки.
9. Плавное появление края эмиссии: отображение **Circles Filled** (Points игнорируют радиус); **nxScale ▸ Range**: радиус от 0 → до ~0.001 (0.01 для тестов во viewport), за 8 кадров с вариацией 50%; дольше (например 25 кадров) = мягче растушёвка. Пропустите, если форма эмиссии (логотип/текст) должна читаться чётко.

## Вариации
- Эмиссия из **вершин** объекта → свободные усики (без констрейнтов); из **рёбер** → завитки, похожие на wireframe; кривые/текст тоже подходят.

## Как сейчас (новые инструменты)
2026.1 beta добавляет списки Falloff по слоям на каждом модификаторе, **nxWarp** (Helix/Path/Flow) для направляемых потоков и **nxFalloff Modifier** для переназначения; сам подход со слоёной турбулентностью актуален.
