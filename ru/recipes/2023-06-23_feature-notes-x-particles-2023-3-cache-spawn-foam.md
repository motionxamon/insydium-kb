# Обзор функций: X-Particles 2023.3 — живой spawn/foam из кэшей, multi-instances, вращение прилипших частиц, xpSplineMesher Planar (Fused 2023.3)

- Источник: INSYDIUM Fused Release Update — July 2023 - X-Particles Sneak Peek — https://www.youtube.com/watch?v=VDzTxgva3dc (2023-06-23)
- Хост / поколение: C4D; G1 CPU X-Particles (xp*), взаимозаменяемо с кэшами NeXus
- Задача: обзор CPU-нововведений X-Particles в июле 2023.

## Живые эффекты из закэшированных сцен
- **xpSpawn** из закэшированного сима: кэш xpExplosiaFX (velocity) + кэш адвектированных частиц → добавить xpSpawn со spawn-эмиттером, запустить → заспавненные частицы по-прежнему адвектируются закэшированным дымом. Увеличьте Spread и добавьте скорость → up-res кэша с малым числом частиц. То же для кэшей **xpFluidFLIP**.
- **xpFoam** на закэшированной жидкости без исходных модификаторов: добавить xpFoam + foam-эмиттер + гравитацию → живая пена. Работает и с жидкостями NeXus; CPU и GPU кэши/пена взаимозаменяемы.

## Другие нововведения
- **xpScatter** и **xpGenerator** поддерживают **multi-instances** → тяжёлая инстанс-детализация остаётся проигрываемой.
- **xpEmitter** — новый режим вращения для правильной ориентации **прилипших** частиц (включите **Local Rotation**).
- **xpSplineMesher ▸ Planar**: ленты из сплайнов xpTrail или любого сплайна; **Plane Up** ориентирует грани, размер, заострённый конец; работает вживую, пока рисуются трейлы; слайдер **Growth** для анимации.

## Как сейчас (новые инструменты)
GPU: **nxUpres** / **nxSpawn** (2026.1 beta) для up-res и спавна, слои nxFoam (2025.4), nxTrail для трейлов; xpSplineMesher остаётся CPU-мешером для лент.
