# Обзор функций: TerraformFX Advanced Terrain Shader — слои, спутниковые палитры, маски (превью Open Beta)

- Источник: INSYDIUM LIVE! — February 2024 – Open Beta Preview, TerraformFX — https://www.youtube.com/watch?v=Foe7aTVhbYs (2024-02-21)
- Хост / поколение: C4D; TerraformFX (tf*) — без частиц; показан в открытой beta, вышел в Fused 2024.2. Работает в любом рендере, который читает шейдеры C4D (в демо — Standard ради мгновенного отклика во viewport).
- Задача: реалистичная окраска low-res tfTerrain, которая выглядит детальной, без ручной покраски и запекания.

## Настройка
- Material ▸ Color ▸ Texture: INSYDIUM shaders ▸ TerraformFX ▸ **Advanced Terrain Shader**; кликните по превью и задокируйте редактор (интерфейс ведёт себя как отдельный плагин). Перетащите **tfTerrain** в поле ссылки на террейн. Новые tfTerrain получают этот шейдер автоматически.
- **Стек слоёв** как в Photoshop, по умолчанию режим Normal (верхний слой перекрывает остальные). Переименовывайте слои (base rock, snow…), чтобы не запутаться.

## Слой Terrain — каналы, смешанные в ч/б карту
- **Slope** (порог — напр. 44% = всё круче становится белым), **Altitude** (отрицательное значение = инверсия), **Curvature** (выпуклое белое / вогнутое чёрное, отлично для детализации), **Ambient Occlusion** (Radius: большой = темнеют только пики; маленький = мелкие канальцы; Quality, Bias).
- **Variation** = крупный глобальный noise со Scale (лёгкий разброс цвета, напр. по лугу); **Jitter** = очень мелкий noise — в малых дозах имитирует дополнительное разрешение и смягчает резкие переходы цвета.
- Выключите **Enable Palette Coloring**, чтобы увидеть ч/б результат; включённая — палитра раскладывается от чёрного к белому.

## Палитры
- Взяты с реальных спутниковых снимков, сгруппированы по **странам** (по умолчанию Spain ▸ Spain 13; India, Congo, United Kingdom…) плюс **Surfaces** внизу списка (Rock, Snow, Sand…).
- Правый клик ▸ Favorites; **Export** в C4D Gradient для использования где угодно. Можно выбрать поддиапазон, **Repeat** палитры, **Bias** к тёмному/светлому краю; переключатель **Normalize** (выкл. = темнее, не весь диапазон).

## Маски и постобработка
- Любой слой может быть маской: перетащите его дочерним под другой слой. Маски можно маскировать (вложить вторую маску под первую).
- Показанные источники масок: слой **Curvature** (режим: впадины), слой **Terrain Operator** (ссылка на террейн или отдельный оператор; Altitude / Slope / Curvature / Bumps / Dents), Object layer/mask (из tfDistribute, см. part-b), C4D Fields.
- Постобработка слоя: Brightness/Contrast, Gamma, **Gradation Curve** (выбор ведущего — поменять концы местами для инверсии, «сжать» для контраста). **Preview Current Layer** включает соло слоя.

## Показанные примеры
1. Снежный пейзаж: слой Terrain «base rock» (Surfaces ▸ Rock, тёмный; меньше altitude, больше curvature, немного variation/jitter) → слой Terrain «snow» (Surfaces ▸ Snow) под маской слоя Curvature (впадины) с кривой контраста → снег заполняет углубления, скала проступает.
2. Пустоши Йоркшира: base rock → бурая вересковая трава (палитра United Kingdom) под маской Terrain Operator **Slope**, кривая инвертирована, чтобы крутые склоны оставались скалой → слой **Agricultural Structures** (распределение Grid или Random, Count ~150, Irregularity) под маской инвертированного **Altitude**, с дочерней маской **Slope**, чтобы на крутых низинах не было полей.

## Разрешение
- **Resolution: Auto** у шейдера = сегменты террейна (в демо 1000×1000). Поднимите (напр. 1500) для крупных планов без пересборки меша; максимум по умолчанию 4000×4000, до 8000 в настройках; стоит времени рендера. Можно запечь в высоком разрешении.

## Что заменяет
Самосборные gradient/layer-шейдеры на tf-каналах или vertex map; в другом рендере подайте шейдер в ноды цвета, roughness и bump/normal.

## Как сейчас (новые инструменты)
Это по-прежнему актуальный инструмент текстурирования TerraformFX (с Fused 2024.2; более новых инструментов TerraformFX не заявлено). С Redshift в C4D 2024+ поднимите разрешение запекания для не-нативных шейдеров (по умолчанию 128×128).
