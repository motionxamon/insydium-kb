# Большой зацикленный океан без заметного тайлинга (xpOcean Looping + второй xpOcean как Deformer)

- Источник: Top Tip Tuesday — Looping Ocean — https://www.youtube.com/watch?v=xQFbyD2fMNo (2023-06-27)
- Хост / поколение: C4D; G1 CPU X-Particles (генератор xpOcean)
- Задача: большой штормовой океан с крупной зыбью, бесшовно зацикленный на 180 кадров и не выглядящий повторяющимся при увеличении масштаба.

## Шаги
1. X-Particles ▸ Generators ▸ **xpOcean**. Width / Height segments по **200** для детализации. [▶ 0:47](https://youtu.be/xQFbyD2fMNo?t=47)
2. Settings: **Wind Speed** сильно вверх (штормовая зыбь), Wave Height немного поднять, **Time Scale** вниз (движение медленнее). [▶ 5:34](https://youtu.be/xQFbyD2fMNo?t=334)
3. Базовый шум Тессендорфа **Resolution 256** (512 детальнее, но плейбэк тормозит). [▶ 1:56](https://youtu.be/xQFbyD2fMNo?t=116)
4. **Choppiness**: поднимайте, пока гребни только начнут заворачиваться, и остановитесь (перебор ломает меш). [▶ 2:22](https://youtu.be/xQFbyD2fMNo?t=142)
5. **Damping 0** = вода плещется туда-сюда, как в закрытом баке; **полный** damping = сильное течение вдоль **Wind Direction** (по умолчанию +Z; меняйте направление, чтобы рулить). Остановитесь на частичном damping — течение с небольшими отражениями. [▶ 2:59](https://youtu.be/xQFbyD2fMNo?t=179)
6. Цикл: включите **Looping**, **Loop Time = последний кадр + 1** (**181** для сцены в 180 кадров). [▶ 3:43](https://youtu.be/xQFbyD2fMNo?t=223)
7. Против тайлинга: продублируйте океан, оригинал отключите. На копии: Resolution **128**, поднимите **Smallest Wave** (сглаживание), сильно увеличьте **Ocean Size**, побольше высоты волн, немного choppiness; подкрутите wind speed / time scale. [▶ 5:16](https://youtu.be/xQFbyD2fMNo?t=316)
8. Копия ▸ Type Primitive → **Deformer**; снова включите оригинал и сделайте океан-деформер его дочерним объектом → крупномасштабное вторичное движение разбивает повторяемость. При необходимости добавьте ещё океанов-деформеров. [▶ 5:58](https://youtu.be/xQFbyD2fMNo?t=358)

## Как сейчас (новые инструменты)
**nxOcean** (NeXus 2026.1 beta, GPU): спектры Phillips / Pierson-Moskowitz / JONSWAP, пена, брызги, кильватерные следы, береговые линии и пляжи, связка с FLIP. В стабильном Fused 2025.4 GPU-океана нет (для взаимодействия — nxWave во FLIP); xpOcean, как в видео, остаётся запасным вариантом. См. "Custom object ocean" (2025-04-08).
