# Простой риг крыла летучей мыши (C4D Joint tool, IK-цепочки, pole vector, IK Dynamics, Mirror tool)

- Источник: Bite-Sized — Rigging Bat Wings — https://www.youtube.com/watch?v=sDGgDroAl1E (2025-07-17)
- Хост / поколение: только нативные Character-инструменты C4D (без объектов INSYDIUM)
- Задача: простой риг машущего крыла летучей мыши с пружинящими костями пальцев, отзеркаленный на обе стороны.

## Шаги
1. Вид сверху: **Joint tool**, Ctrl-клик, чтобы расставить плечо → плечевую кость → лучевую/запястье (цепочка руки). Кликните в пустое место, затем нарисуйте три отдельные цепочки по 3 джоинта для основного, среднего пальца и мизинца. Перемещение джоинта сдвигает/масштабирует соседние. [▶ 0:25](https://youtu.be/sDGgDroAl1E?t=25)
2. Назовите всё с префиксом стороны для зеркалирования: `R_shoulder`, `R_H` (плечевая), `R_R` (лучевая), `R_W` (запястье), `R_mainfinger…`, `R_middlefinger…`, `R_pinky…`. Цепочки пальцев сделайте дочерними к запястью. [▶ 3:42](https://youtu.be/sDGgDroAl1E?t=222)
3. Выделите плечевую + запястье (лучевую пропустите) ▸ Character ▸ **Create IK Chain** → IK-тег + null-цель на запястье. [▶ 3:51](https://youtu.be/sDGgDroAl1E?t=231)
4. Контроллер: Cube ▸ make editable ▸ выделить все рёбра ▸ **Edge to Spline**; уменьшите, яркий цвет отображения, поставьте на запястье; назовите `R_wing_controller`, дочерним к плечу; null-цель → дочерней к контроллеру. [▶ 4:31](https://youtu.be/sDGgDroAl1E?t=271)
5. Джоинт запястья ▸ тег **Transform Constraint**, только вращение, цель = контроллер (поверните контроллер, чтобы убрать переворот) → пальцы следуют вращению контроллера. [▶ 5:36](https://youtu.be/sDGgDroAl1E?t=336)
6. **Pole vector**: null `pole` с отображением синей сферой; перетащите его в поле Pole Vector IK-тега; Display ▸ линия pole от **Joint** вместо Root. Не даёт локтю переворачиваться. [▶ 7:30](https://youtu.be/sDGgDroAl1E?t=450)
7. Динамика пальцев: Create IK Chain на каждой цепочке пальцев, **удалите созданные цели**, выделите три IK-тега ▸ Dynamics ▸ **Enable** (работает только при проигрывании; слайдер Strength задаёт пружинистость). [▶ 8:51](https://youtu.be/sDGgDroAl1E?t=531)
8. Выделите плечо ▸ **Mirror tool** ▸ Naming: заменить `R_` на `L_` ▸ Mirror. Анимируйте оба контроллера для взмаха. [▶ 9:40](https://youtu.be/sDGgDroAl1E?t=580)

## Подводные камни
- Динамика считается только при проигрывании — для теста удлините таймлайн.
- Управления пальцами нет; это базовый риг для существа на заднем плане.
