# Рост растения с проигрыванием ключевой анимации раскрытия листьев (анимированные модификаторы toLeaf как Custom-лист в toPlant, режимы ключей во вкладке Growth)

- Источник: Top Tip Tuesday — toPlant Keyframe Growth — https://www.youtube.com/watch?v=KBSBpoeeVPo (2023-07-18)
- Хост / поколение: C4D; Taiao (toPlant, toLeaf)
- Задача: листья растущего растения раскрываются по собственной ключевой анимации, а не просто проявляются через масштаб.

## Исходная сцена
toPlant со слоем Trunk и слоем Leaf в режиме геометрии **Basic** (форма изгиба, furling, угол). Обычный рост (глобальный или послойный с вариацией) только масштабирует листья — выглядит фальшиво.

## Шаги
1. Соберите один **toLeaf**, у которого в стеке Modifiers есть Bend, Fold, Furling плюс **три дополнительных слоя Furling с ключами на Furling Angle**: один для основного раскрытия, один только на кончике, один — более широкий общий изгиб → раскрытие без самопересечений. [▶ 1:57](https://youtu.be/KBSBpoeeVPo?t=117)
2. toPlant ▸ Plant Layers ▸ слой Leaf ▸ Geometry: Basic → **Custom**, перетащите туда анимированный toLeaf. [▶ 2:45](https://youtu.be/KBSBpoeeVPo?t=165)
3. При простом проигрывании анимации листьев не видно: toPlant ▸ вкладка **Growth** ▸ нажмите **значок ключа** на слое Leaf, чтобы открыть опции анимации. [▶ 3:14](https://youtu.be/KBSBpoeeVPo?t=194)
4. Режим **Growth Slider**: анимация слайдера масштабирует и раскрывает листья. Trigger **Random** (по умолчанию) или **Sequence** (снизу вверх). [▶ 3:39](https://youtu.be/KBSBpoeeVPo?t=219)
5. Режим **Global Growth Slider**: управляет глобальный рост растения; листья раскрываются снизу вверх по мере роста. [▶ 3:54](https://youtu.be/KBSBpoeeVPo?t=234)
6. Режим **Animate Slider**: отдельный слайдер только для анимации листьев (Sequence или Random), а слайдер роста по-прежнему отвечает за масштаб. [▶ 3:39](https://youtu.be/KBSBpoeeVPo?t=219)
7. Trigger **Field**: добавьте **Linear field**, направленное по **−Y**, с сильно уменьшенной длиной; анимируйте его вверх по растению → листья раскрываются по мере прохождения поля. [▶ 5:00](https://youtu.be/KBSBpoeeVPo?t=300)
8. Работает и с кастомными объектами toFlower. [▶ 5:26](https://youtu.be/KBSBpoeeVPo?t=326)
