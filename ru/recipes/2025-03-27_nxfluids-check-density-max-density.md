# Больше частиц в жидкость без взрыва давления (nxFluids Check Density / Max Density)

- Источник: Bite-Sized — Fluids Sims Check Density — https://www.youtube.com/watch?v=0b6vrPWXjQg (2025-03-27)
- Хост / поколение: C4D; xpEmitter + NeXus GPU nxFluids (SPH и PBD)
- Задача: ровная струя, быстро наполняющая резервуар, без разлёта в стороны.

## Исходная сцена
Коллайдер-контейнер, гравитация по умолчанию, **nxFluids** по умолчанию (SPH). xpEmitter сферической формы, эмиссия **Rate** случайно внутри объёма, **2,000/s**, скорость 0 → чистая струя.

## Шаги
1. Поднимите Birth Rate до **10,000/s** → струя разлетается. Причина: новорождённые набиваются в тот же объём каждый кадр, прежде чем старые его покинут, плотность жидкости резко растёт, и давление солвера расталкивает частицы (солвер ведёт себя правильно).
2. nxFluids ▸ SPH ▸ включите **Check Density** (по умолчанию **110%**) → новорождённые с плотностью выше порога удаляются; струя снова спокойная.
3. Компромисс: полных 10,000/s уже нет. Поднимайте **Max Density**, чтобы пропустить больше: 130 = струя чуть шире, 160 = заметно больше частиц, 200 = разлёт от давления возвращается. В демо остановились на **130**.
4. В режиме **PBD** есть та же опция Check Density и работает так же (выкл. = взрывное рождение, вкл. = стабильно).

## Как сейчас (новые инструменты)
Для плотных жидкостей сегодня — nxFluids FLIP/APIC (Fused 2025.4); в 2025.4.1 FLIP-частицы можно красить по particles-per-voxel, а бета 2026.1 добавляет Recolor by Density — удобно, чтобы найти переуплотнённую эмиссию.
