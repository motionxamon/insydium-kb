# Обзор функций: nxFollowGeo, слоёный nxColor и nxCover (NeXus 2024.2)

- Источник: NeXus Sneak Peek – Modifiers, Release Update Coming Soon 2024.2 — https://www.youtube.com/watch?v=xT2xM7jM4Pc (2024-04-22)
- Хост / поколение: C4D; GPU-модификаторы NeXus на оранжевых xpEmitters (G2), вместе с nxTurbulence и nxFluids
- Статус: превью **Fused 2024.2** (9 мая 2024)

## nxFollowGeo (новый)
- Частицы следуют по **поверхности** объекта (с **Offset**) или по **рёбрам** полигонов (со сглаживанием рёбер для более плотного движения); движение даёт nxTurbulence.
- Добавьте **nxFluids** (по умолчанию) — получится жидкость, обтекающая поверхность, или симуляция капель по рёбрам; режим surface ↔ edge можно анимировать.
- **Несколько объектов в одном модификаторе, у каждого свои настройки** (утка в режиме Edge, волк в Surface притягивает капли по мере приближения) — Object Manager остаётся аккуратным.
- Работает со **сплайнами** (Offset Variation для разброса) и с анимированными объектами/сплайнами (например, тег Vibrate).
- Заменяет CPU xpFollowSurface / xpFollowSpline.

## nxColor (новый GPU-модификатор цвета, стек слоёв)
- Слои: **Gradient by Parameter** (например, **Speed**: быстрые = жёлтые, медленные = чёрные; **Distance travelled**; случайный **Noise** для зерна), **Set Color** (один цвет или **shader**, например битмап логотипа с выключенным тайлингом).
- У каждого слоя **blend mode** (Normal, Multiply, Minimum, Overlay…) и Strength; верхние слои перекрывают/смешиваются с нижними.

## nxCover (новый)
- Покрывает частицами объекты или **сплайны** (текстовый сплайн слоем, режим по скорости частиц — стильное прописывание).
- Режимы для объектов: **Points, Edges, Polygon area, Volume** и **Particle Ray** — частицы покрывают только те точки, которые видят напрямую (задние грани остаются пустыми).
- Несколько объектов в списке: режим **Sequence** проходит по ним по очереди; **Hold Time** и вариация задают момент переключения; **Object Index** выбирает элемент списка (0 = первый), его можно анимировать.

## Как сейчас (новые инструменты)
nxColor вошёл в слоёные модификаторы Fused 2025.4 (GPU-falloff и mapping на каждый слой, слой Noise); nxFollowGeo получил мульти-сплайн и режимы Guide/Force. Для потоков по траектории в 2026.1 рассмотрите также **nxWarp** (Path/Helix/Flow). См. «nxFollowGeo surface fluid» (2024-05-14) и «nxCover turbulent spline reveal» (2024-05-21).
