# Струя воды размывает комковатый песок (nxFluids SPH Granular + жидкость в Mixer, цвет nxBlend → mapped-настройки granular)

- Источник: Top Tip Tuesday — Sand & Water Mix — https://www.youtube.com/watch?v=yp5579on6J8 (2026-09-08)
- Хост / поколение: Blender (NeXus for Blender 2026.0) — nxFluids SPH (Granular + Mixer), nxBlend, nxFluids Mapping, nxCollider
- Задача: падающий тор из сыпучего материала, в который бьёт струя жидкости, размягчая и смывая песок, которого касается.

## Шаги
1. Плоскость пола + тор (оба скрыты). **Sand nxEmitter**: Object ▸ тор, **Volume**, **Shot**, **Hexagonal**, Speed 0; Display Spheres, Gradient по **Granular**, Auto Scale выкл, 0–20.
2. **nxGravity**; **nxCollider** на плоскости, Bounce 0, немного Friction.
3. **nxFluids** ▸ **SPH** (нужен, чтобы смешивать granular + жидкость), основной Fluid Type **Granular** — песок настраивается в главной панели, жидкость в Mixer. Substeps **Adaptive выкл, 15**; Friction **100**.
4. Больше песчинок: радиус песка **0.015 m** (количество в Hex зависит от радиуса; 7k по умолчанию — слишком мало).
5. **Water nxEmitter**: Sphere, радиус 0.2, размещён вдоль Y; **Rate** + режим Hex; направление **−Y**, скорость **3.5**. **Radius 0.015 — должен совпадать с песком**; разные радиусы заставляют SPH взрываться.
6. nxFluids ▸ **Mixer** ▸ добавьте эмиттер воды как **Liquid**. Включите **Check Density**, чтобы убивать слишком плотные рождения (убирает взрывной старт).
7. Раздельные коллайдеры: эмиттер воды ▸ Modifiers ▸ поставьте липкому коллайдеру **минус (игнорировать)**; добавьте второй коллайдер (та же плоскость, Bounce 0, Friction ~3) и сделайте так, чтобы эмиттер песка его игнорировал. Переименуйте эмиттеры/коллайдеры в sand/liquid.
8. Пометка контакта: песок — Single color чёрный (значение 0), вода — белый (значение 1).
9. **nxBlend** ▸ Color, режим **Addition**, Distance **0.04 → 0.07**, Strength **500%** (может быть больше 100) → белый расползается по мокрому песку; задайте max/stop frame (148, затем **110**), чтобы остались твёрдые чёрные комки.
10. nxFluids ▸ **Mapping** ▸ три карты **Color Brightness** → **Friction**, **Stability**, **Cohesion**, кривые инвертированы (чёрный = полное значение, белый ≈ 0), чтобы мокрые песчинки крошились и смывались.

## Подводные камни
- Одинаковый радиус у всех SPH-эмиттеров обязателен.
- Высокий friction подходит песку, но делает жидкость липкой — отсюда списки игнорируемых коллайдеров для каждого эмиттера.

## Как сейчас (новые инструменты)
В 2026.1 beta **nxMPM** обрабатывает песок + жидкость как материалы, со **сменой материала по возрасту/скорости/растяжению/повреждению** (Mixer); FLIP Mixer добавляет viscosity/yield stress для каждой группы.
