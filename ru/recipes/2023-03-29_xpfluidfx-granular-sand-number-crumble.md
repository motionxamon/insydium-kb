# Песочная цифра, которая рассыпается на комки (xpFluidFX Granular, Hexagonal-заполнение, анимированный falloff гравитации)

- Источник: Maintenance Training — XP Countdown - Series 2 - xpFluidFX Granular — https://www.youtube.com/watch?v=SMO0CZcHa3k (2023-03-29)
- Хост / поколение: C4D; CPU X-Particles (xpFluidFX granular, xpGravity, xpKill, xpColor, xpCache) — до NeXus-granular / до MPM
- Задача: MoText «3», заполненная песчинками, трескается на комки и падает назад на коллайдер «2» (дальше её разносит дым через advection).

## Исходная сцена
- MoText «3» (глубина 25 см) сдвинута на Z −12.5, чтобы совпасть с предыдущей цифрой; дубликат → коллайдер «2» на Z +12.5 с тегом **xpCollider** (низкий Bounce, высокий Friction), чуть увеличен, чтобы под большей частью тройки была опора.
- xpSystem ▸ xpEmitter «emitter grains»: Display Circles Filled + **Ambient Occlusion** во viewport (чтобы читались комки), HUD включён.

## Шаги
1. Эмиттер ▸ **Object** = тройка; тип эмиссии **Hexagonal** (заполнение без пересечений), снять эмиссию каждый кадр, end frame 1, скорость 0. [▶ 7:53](https://youtu.be/SMO0CZcHa3k?t=473)
2. Радиус задаёт количество: 3 см ≈ 800, 1.5 ≈ 6 400, 1.2 ≈ 13 000, 0.9 ≈ 30 000, **0.8 ≈ 43 000** (финал). [▶ 30:50](https://youtu.be/SMO0CZcHa3k?t=1850)
3. Добавить **xpFluidFX**; гранулярный режим включается на эмиттере: **Extended Data ▸ Fluid Data ▸ Fluid Type: Granular** → остаются только Friction, Stability, Cohesion (все влияют друг на друга). [▶ 9:38](https://youtu.be/SMO0CZcHa3k?t=578)
4. xpFluidFX **Accuracy Fast → High** — granular нужно много substeps/итераций, иначе комки не становятся жёсткими. [▶ 15:01](https://youtu.be/SMO0CZcHa3k?t=901)
5. **xpGravity** повернуть на 90°, чтобы тянула в +Z (от камеры); бокс **xpKill** позади сцены убирает упавшие песчинки.
6. Анимация осыпания: у гравитации **Falloff ▸ Box field**, ключи по Z — от низа буквы и дальше неё за ~40 F, F-кривая **Linear**. [▶ 23:12](https://youtu.be/SMO0CZcHa3k?t=1392)
7. Трение о коллайдер: **Extended Data ▸ Physical Data ▸ Friction** на эмиттере — это пер-частичный множитель значения коллайдера (по умолчанию 20%) → поставить 100% и дальше крутить только на теге коллайдера (100 = песок прилипает, 70 → 90 на финальном количестве). [▶ 32:12](https://youtu.be/SMO0CZcHa3k?t=1932)
8. Что делают настройки granular:
   - **Friction** (между песчинками): мало — сухая соль сыпется, много — комки; слишком много — жёсткие глыбы, которые съезжают целиком.
   - **Stability**: насколько песчинки держат форму — основные изменения примерно в диапазоне 4–20; мало = много мелких кусков, много = несколько крупных.
   - **Cohesion**: пружинистое удержание через трещины; рабочий диапазон ~10–30; слишком много — желейная, шатающаяся упругость.
   - Итог: friction меньше, stability больше, cohesion сначала задрана, потом остановились на **30** (без заметного отскока, больше песка остаётся на двойке).
9. Цвет для рендера: **xpColor** ▸ Gradient by Parameter ▸ **3D Linear**, ось Z, Min −12.5 / Max 12.5, **Change on Birth Only**; градиент чёрный → белый, чтобы перекрасить на рендере, а в трещинах проступали светлые внутренние песчинки. [▶ 18:08](https://youtu.be/SMO0CZcHa3k?t=1088)
10. Тестовые cache: **xpCache** internal, Data **Custom** = только Velocity + Color, без компрессии (~30–40 с на тест). Систему переименовать в «XP system grains». [▶ 33:52](https://youtu.be/SMO0CZcHa3k?t=2032)

## Подводные камни
- Рост количества частиц меняет физику — после каждого скачка разрешения заново подбирать friction/stability/cohesion.
- Начальный упругий отскок от cohesion можно пропустить, начав рендер cache на несколько кадров позже (в демо — с 9-го кадра).

## Как сейчас (новые инструменты)
Материалы песка/снега **nxMPM** (2026.1 beta, presets nxMaterial «Sand wet», per-emitter «Sand Dry») с гравитацией через nxFalloff; стабильный путь в Fused — **nxFluids SPH Granular** на GPU. См. рецепты 2023-03-07 и 2026-07-28.
