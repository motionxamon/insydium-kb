# Как спрятать гексагональную сетку в сыпучих симуляциях (Jitter эмиттера + nxPush на один кадр + Initial State)

- Источник: Top Tip Tuesday — Jitter Grid Particles — https://www.youtube.com/watch?v=XwX71yF7O5M (2025-04-01)
- Хост / поколение: C4D; NeXus внутри X-Particles (nxFluids SPH Granular, nxPush, nxGravity)
- Задача: стабильная упаковка гранул без заметного регулярного гексагонального узора на рендере и без взрыва на старте.

## Исходная сцена
Эмиттер с объекта (модель лисы), **Shot Hexagonal, радиус 4 cm**; nxGravity + **nxFluids SPH Granular**. Симулируется нормально, но гекс-решётка на рендере бросается в глаза.

## Шаги
1. Вкладка Emission ▸ **Jitter X/Y/Z ≈ 3** → сетка разбита… но теперь частицы перекрываются → высокая плотность → взрыв давления на первом кадре. [▶ 1:45](https://youtu.be/XwX71yF7O5M?t=105)
2. Отключите гравитацию и флюиды. Добавьте **nxPush**: режим **Particle Radius**, **Strength 100**, **Iterations ~200** (всё расталкивание должно произойти за один кадр; больше частиц → больше итераций). [▶ 3:15](https://youtu.be/XwX71yF7O5M?t=195)
3. Шагните на кадр вперёд — частицы слегка разойдутся. Верните как было (push выкл., gravity + fluids вкл.) → масса чисто осыпается, без взрыва. [▶ 3:46](https://youtu.be/XwX71yF7O5M?t=226)
4. Более мелкий вариант: радиус **2 cm**, jitter **2.2**, итераций push **~1,500** (один кадр считается дольше). [▶ 4:49](https://youtu.be/XwX71yF7O5M?t=289)
5. Запеките: эмиттер ▸ Object ▸ **Initial State ▸ Set State** после кадра с push; режим Emission → **Controlled Only**, чтобы ничего нового не эмитилось. Удалите/отключите nxPush. [▶ 6:19](https://youtu.be/XwX71yF7O5M?t=379)

## Подводные камни
Мало итераций push = остаточные перекрытия = взрыв при включении флюидов. Мелким частицам нужно меньше jitter, но гораздо больше итераций.

## Как сейчас (новые инструменты)
В NeXus 2026 workflow тот же (у nxEmitter есть **Initial State** + Keep Stored Age; nxPush не изменился). Для поведения песка более новый вариант солвера — **nxMPM** (материал sand) из беты 2026.1.
