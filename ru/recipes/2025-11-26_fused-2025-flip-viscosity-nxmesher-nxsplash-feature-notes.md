# Обзор функций: жидкости в Fused 2025 — GPU FLIP/APIC с вязкостью, nxMesher, nxSplash (Final Tech Preview)

- Источник: Fused 2025 Tech Preview — INSYDIUM Fused 2025 Final Tech Preview — https://www.youtube.com/watch?v=mWj3nWcfbSQ (2025-11-26)
- Хост / поколение: C4D; NeXus G2 (nx-модификаторы на xpEmitter’ах) в бете Fused, вышедшей как 2025.4; рендер в Redshift
- Задача: обзор новых GPU-инструментов для жидкостей — солвер FLIP/APIC со встроенной вязкостью, GPU nxMesher, коронные всплески nxSplash.

## nxFluids FLIP / APIC (новый солвер рядом с PBD и SPH)
- Солвер на воксельной сетке с двумя режимами: **FLIP** (высокий FLIP Fraction, по умолчанию **95%** = шумно, много брызг, средний/крупный масштаб) и **APIC** (более гладкий, сохраняет угловой момент — рябь долго бежит и отражается от стенок).
- Пониженный FLIP Fraction (≈**60%**) сглаживает поток и убирает шумную детализацию поверхности — хорошо для густой слизи и мелких всплесков.
- **Viscosity**: 0 = выкл.; любое значение > 0 включает отдельный солвер вязкости (100 = тягучая слизь).
- **Вкладка Mapping** (источник FLIP/APIC) для переменной вязкости, например **Particle Speed**: полная вязкость до 5 cm/s, плавно спадает к 15 cm/s и выше (быстрые участки растекаются плёнкой, медленные — сгустками).
- **Friction** в Collider tag помогает жидкости прилипать к коллайдеру (бюсту).
- С ним работают все nx-модификаторы: **nxWind** Strength 250, режим **Von Karman** для порывов; **nxRotate**, поставленный вертикально в центре бака, — для водоворота; nxTurbulence; **nxDirection**, чтобы сымитировать скоростной поток без гравитации.
- Плёночные всплески в APIC: Surface Tension **5**, **Weak Particle Repulsion 10**, чтобы держать тонкие плёнки.

## Растопленный шоколад, который застывает (вязкость по цвету)
1. Ширина эмиттера ≈ 0 (толщина в одну частицу) → тонкие складывающиеся ленты.
2. **nxQuestion**: Object Distance < **3 cm** до полигонов мороженого → Set Color белым с низким Weight (проявляется постепенно).
3. nxFluids Viscosity **150**; Mapping ▸ **Particle Color** → вязкость (чёрный = низкая, но не нулевая, белый = полная).
4. **nxBlend** Mode **Add**, Distance **5 cm**, Strength 100 → частицы только светлеют, поэтому остатки застывают быстрее.
5. nxMesher с вершинным цветом → в Redshift roughness различается на жидких и застывших участках.

## nxMesher (GPU)
- Перетащите эмиттеры в его слои. Тип поверхности **Spheres** (как VDB, нужны слои сглаживания) или **Zhu-Bridson** (чистые гладкие плёнки без фильтров).
- Демо со слизью: Radius **2**, Polygon Size **1.5**. Демо со складками: Radius **0.8**, Polygon Size **3**, слой сглаживания **Mean Curvature**, Iterations **10–13** (сохраняет складки, выравнивает плоские участки).
- **Export Tags ▸ Transfer Color** → Color vertex tag (управляет цветом SSS в материале); можно передать и скорость.

## nxSplash (конструктор коронных всплесков)
- Torus-эмиттер + nxSplash, FLIP активен. Ручки формы верхнего/нижнего радиуса плюс ручки мощности; Height, Strength (100 → 80% для APIC).
- N пиков = **2N ручек мощности**: 10 ручек, каждая вторая опущена → 5 пиков; подтяните верхние ручки формы у ручек с низкой мощностью для формы лепестков; немного рандомизируйте пики.
- Для плёнок поднимите количество частиц (5,000 → **20,000 в кадр**).
- FLIP при FLIP Fraction 58 загибается вниз аркой; APIC дольше держит настоящую корону.

## Макросъёмка всплесков
- Быстрый эмиттер в коллайдер (лимон), без гравитации, толчок nxDirection; для детализации нужна очень плотная воксельная сетка и много substeps солвера.
- Корона с обволакиванием принудительно: скрытый цилиндр-коллайдер с **Displacer** (noise) + деформером **Smoothing** на пути; смена seed у noise каждый раз даёт новый всплеск.

## Что заменяет
CPU xpFluidFLIP / вязкость xpFluidFX, xpOpenVDBMesher (→ nxMesher), вручную собранные эмиттеры коронных всплесков (→ nxSplash). Ещё новее: в бете 2026.1 у FLIP неньютоновские жидкости (Flow Index, Yield Stress), Wall Friction и Mixer.
