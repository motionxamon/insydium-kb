# Лента частиц, обёрнутая вокруг сплайна деформерами C4D (Spline Wrap + Twist на xpEmitter)

- Источник: Bite-Sized — Deforming Particles — https://www.youtube.com/watch?v=K2Jb2lxzgSY (2025-05-08)
- Хост / поколение: C4D; G2 xpEmitter + GPU nxTurbulence, nxAttract, nxKill; родные деформеры C4D дочерними к эмиттеру
- Задача: тонкий шумный поток частиц, который точно идёт по helix-сплайну и закручивается вокруг себя; всё процедурно и анимируемо.

## Шаги
1. **xpEmitter** + **nxTurbulence**: Noise **Voronoise**, Strength **40**; масштаб направления по оси **Y = 0** → плоская лента.
2. Держим направление +Z: **nxAttract** с целью впереди потока, Mode **Velocity**, Acceleration **10**, Speed Limit **400**, Force **50**.
3. **nxKill** с боксом: **Volume ▸ Inside bounds** у аттрактора, чтобы частицы гибли по прибытии. Kill и аттрактор скройте.
4. Деформер **Spline Wrap** **дочерним к эмиттеру**: Axis **+Z**; он автоматически подстраивается под эмиттер, так что увеличьте bounding size (длину по +Z и ширину) на глаз, пока весь поток не окажется внутри.
5. Бросьте **Helix** в поле Spline → лента точно повторяет спираль. Анимируйте Start Radius / End Angle спирали — изменения видны вживую.
6. Закрутка вокруг себя: деформер **Twist**, в координатах **Pitch 90°** (с −90° скручивает не с того конца), дочерним к эмиттеру, по центру потока; увеличьте **Y bounding size**, включите **Unlimited**, затем подберите угол.
7. Комбинация: Spline Wrap **ниже** Twist (оба дочерние к эмиттеру) → скрученная лента на спирали (с большими радиусами спирали читается лучше).

## Подводные камни
- Порядок деформеров под эмиттером важен (сначала twist, потом wrap).
- Bounding box должен охватывать все частицы, иначе часть останется недеформированной.

## Как сейчас (новые инструменты)
**nxWarp** (бета 2026.1) делает это нативно: варпы Path или Helix в режиме Deform/Guide, общий параметр Twist, варпы складываются в стек; стабильный путь — nxFollowGeo в режиме сплайна с Twists.
