# Скиннинг крыльев летучей мыши с тканевой перепонкой (C4D Bind heat map + Cloth + Cloth Belt)

- Источник: Bite-Sized — Skinning Bat Wings — https://www.youtube.com/watch?v=7pn1nJKwxZs (2025-07-31)
- Хост / поколение: только нативные инструменты C4D для персонажей и ткани (продолжение предыдущего видео про риг крыла летучей мыши); без объектов INSYDIUM
- Задача: меш руки заскинен на риг, перепонка симулируется как ткань, прикреплённая к пальцам и телу.

## Исходная сцена
Отдельные объекты: меш руки/пальцев и перепонка крыла (для ткани перепонка должна быть отдельной); риг из джойнтов + контроллеры-нули; короткая анимация взмаха.

## Шаги
1. Выделите джойнты: правый клик по корню ▸ **Select Children**, Ctrl-клик, чтобы снять выделение с нулей, Ctrl-выделите меш руки.
2. Character ▸ **Bind**, режим **Heat Map** (альтернативы Distance, Volumetric), по умолчанию → под мешем появляется деформер **Skin**.
3. Проверьте через Character ▸ **Weight Tool** (выберите джойнт, чтобы увидеть/подрисовать веса); здесь хватило значений по умолчанию.
4. Перепонка: заранее сделанные **selection sets** точек вдоль пальцев и края крыла + второй набор со стороны тела.
5. Перепонка ▸ Simulation Tags ▸ **Cloth** (по умолчанию).
6. Simulation Tags ▸ **Cloth Belt** → Belt On = меш руки, выберите набор точек, **Set** (точки перекрашиваются), влияние 100%.
7. Перепонка со стороны тела провисает: добавьте скрытый **Cylinder** (по Z, уменьшенный), **сделайте его редактируемым** (belt не работает с параметрическими объектами), второй Cloth Belt к нему со вторым набором точек.
8. Снова включите теги **dynamics** на джойнтах пальцев из рига; вернитесь на кадр 0, проигрывайте с включённым Subdivision Surface.
9. Посмотрите полную пару через объект **Symmetry**.

## Как сейчас (новые инструменты)
Путь INSYDIUM (бета 2026.1): ткань на nxConstraints с **nxPin** (pin To Object) или nxDeformer, управляющим перепонкой; CPU xpClothFX в Fused. Нативная ткань C4D, как в видео, — самый простой вариант для этой задачи.
