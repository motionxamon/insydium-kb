# Запуск сима жидкости переносом частиц в новую группу (nxQuestion Field + Random math, Set Group)

- Источник: Top Tip Tuesday — nxQuestion Change Group — https://www.youtube.com/watch?v=xCo2B_o5VeQ (2023-09-12)
- Хост / поколение: C4D; G2 NeXus внутри X-Particles (оранжевый xpEmitter, nxFluids SPH, nxGravity, nxAvoid, переработанный nxQuestion из Fused 2023.3)
- Задача: 100k частиц воды замерли на голове волка и падают/разбрызгиваются только там, где проходит растущее поле, с рваным случайным краем.

## Исходная сцена
xpEmitter с головы, Emission **Shot**, случайный тип выброса, **100,000** частиц. **nxFluids** по умолчанию, но солвер **SPH**; стандартный **nxGravity**. Коллизии сымитированы через **nxAvoid** на голове (быстро; если важны протечки, повесьте на меш тег коллайдера).

## Шаги
1. Emitter ▸ Groups: дважды Ctrl+Alt-клик по Create (группы 1 и 2); режим Random → **First Group Only**, чтобы каждая новая частица попадала в группу 1.
2. **nxFluids** и **nxGravity** ▸ Groups Affected: только **group 2**. Теперь при проигрывании ничего не движется.
3. Добавьте **nxQuestion** и C4D **Spherical field**; (поле подключается во вкладке Fields у nxQuestion).
4. nxQuestion ▸ Object: добавьте **Question**, тип данных Age → **Field**, условие **> 0** (считается любое место внутри внешней сферы).
5. Добавьте дочерний **Action**: Set Color → **Set Group**, цель **group 2**. Анимируйте рост поля: частицы, попавшие в него, падают и разбрызгиваются.
6. Сломайте идеально круглую дыру: добавьте второй Question дочерним к первому (Set Group становится его потомком), комбинация **And**, тип **Math ▸ Random**, Min **−100**, Max **100**, условие > 0 → переключается лишь примерно половина частиц внутри.
7. Включите **Time Variation** (новое случайное число каждый кадр) и поднимите порог до **> 80**: за кадр переключается мало частиц, но со временем их накапливается больше → постепенное, рассыпчатое высвобождение.

## Подводные камни
- Порядок важен: actions срабатывают, только если прошли все родительские questions.
- Без Time Variation каждая частица держит одно случайное значение, и «проигравшие» не переключатся никогда.

## Как сейчас (новые инструменты)
Та же схема nxQuestion в NeXus 2026.1 (nxEmitter/nxGroup); вместо поля C4D используйте **nxFalloff** (16 режимов, включая Noise для органичного фронта) или список Falloff на слой у модификаторов. Quill (Blender) может набросать дерево вопросов по промпту. FLIP/APIC (Fused 2025.4) — для более красивого всплеска.
