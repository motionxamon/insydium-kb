# Обзор функций: сплайновые режимы nxFollowGeo, nxUpres по каналам, слои nxSpeed Range

- Источник: Fused 2025 Tech Preview — Modifier Improvements Part 3 — https://www.youtube.com/watch?v=8QT_cE61U2Y (2025-08-14)
- Хост / поколение: C4D; NeXus (nx…) на xpEmitter (G2) — показано заранее, до выхода **Fused 2025.4** (Dec 2025)
- Задача: точная арт-дирекция потока в хаотичных симуляциях, более управляемый upres, процедурная анимация скорости.

## nxFollowGeo — отдельные настройки для сплайнов (заменяет CPU xpFollowSpline / xpSplineFlow)
- Бросьте сплайн в поле ссылки на объект → появятся настройки для сплайна (полигональные объекты по-прежнему работают).
- Ничего не происходит, пока **Activate Range** > 0. Две силы: **Attract** (притяжение к сплайну) и **Follow** (толкает вдоль касательной).
- Режим **Guide**: плотный точный путь (логотипы, проявление текста). Режим **Force**: те же силы, но смешиваются с другими — держите сильный nxTurbulence для шумного органичного потока. Параметрические/анимированные сплайны обновляются вживую.
- **Несколько сплайнов в одном модификаторе**, у каждого свои настройки; поток, попавший в activate range другого сплайна, ответвляется; потоки по-прежнему сталкиваются/плещутся как флюид.
- **Extended ▸ Offset** (например 38 cm) — плоская лента; **Offset Blend** 0 → 100% переключает плоскость, 50% → трубка, похожая на тор; кривая offset по длине сплайна делает сужение (тонко → полностью в середине → тонко).
- **Extended ▸ Twists** (например 5 витков, радиус 35) со своей кривой по длине. Большему радиусу витков нужно больше Attract, затем больше Follow для сглаживания. Комбинируйте Offset + Twist для закручивающихся лент.
- **Release**: Spline End (также по falloff или по времени); On Release: Do Nothing, Kill, Loop, Reverse, **Change Group** (например, в группу, на которую действует только nxGravity → поток падает и разбрызгивается).

## nxUpres — отдельная сила для каждого канала
- Та же схема: закешированный эмиттер-источник + эмиттер-приёмник (те же настройки, больший rate, например 20,000/s, speed 0, radius 0, без анимации цвета). Каждая частица-приёмник смешивается из ближайших (здесь 10) частиц-источников.
- Слайдеры **Velocity, Position, Color, Radius, Mass** вместо одной силы + чекбоксов. Низкий Color = лёгкий оттенок, высокий = совпадение с источником. Низкий Velocity + высокий Position = вид прожилок/усиков. Канал Radius передаёт анимированный радиус источника (нужен режим отображения, показывающий радиус, например Spheres).
- Оставьте nxTurbulence источника в сцене — это даст дополнительную детализацию, согласованную с источником.

## nxSpeed — система слоёв
- Слои (incremental speed, acceleration…) с режимами смешивания; слой **Range** умеет почти всё: начальное/конечное значение, начальное/конечное время, кривая ease, вариация, **Cycle**.
- Выброс и затухание: переверните кривую, чтобы частицы стартовали с конечного значения (например 150) и затухали до начального за 60 F; начальное значение ~1 cm + вариация — как подрагивание в покое; вариация по времени разносит остановку.
- Пульсация: кривая 0 → пик → 0 с **Cycle** (повтор каждые 60 F; например 90 cm). Если нужны явные пульсы, не используйте вариацию по времени при цикле.

## Как сейчас (новые инструменты)
Вышло в Fused 2025.4. В 2026.1 beta потоки формирует ещё и **nxWarp** (режимы Path, Helix, Flow), а слой nxSpeed переименован в **Acceleration** (Beta 3).
