# INSYDIUM KB — X-Particles · NeXus · Fused (RU / EN)

База знаний по INSYDIUM для Cinema 4D и Blender, собранная из документации и ~530 видео канала INSYDIUM (2017 → ноябрь 2026). Упор на новые инструменты: NeXus 2026.1 beta (nxMPM, nxWarp, nxBind…), Fused 2025.4 GPU (FLIP/APIC, nxExplosiaFX, nxMesher, Jidou), NeXus for Blender 2026.0.

**🔎 Сайт с поиском:** https://motionxamon.github.io/insydium-kb/ — поиск по рецептам на русском и английском, «Идея → план» и «Спросить» собирают промпт с нужными файлами базы для вставки в Claude / ChatGPT / Codex, скачивание скилла.

## Как подключить
- **Claude (claude.ai, Projects или Claude Code):** скачай `docs/insydium-kb-ru.zip` (или `-en`) и загрузи как skill, либо положи папку `ru/` в проект.
- **Codex / Cursor / другие агенты:** положи `en/` (или `ru/`) в репозиторий и укажи агенту читать `SKILL.md`.
- **Любой чат:** на сайте нажми «Вся база одним .md» или собери свой контекст звёздочками ☆.

## Важно
- Рецепты — пересказ шагов из видео своими словами, не транскрипты; у каждого есть ссылка на оригинальное видео INSYDIUM.
- Числа взяты из автосубтитров: это ориентир для старта, а не точные значения.
- Неофициальный проект, не связан с INSYDIUM LTD. X-Particles, NeXus, Fused, TerraformFX, Taiao, MeshTools, Jidou — товарные знаки INSYDIUM LTD.
