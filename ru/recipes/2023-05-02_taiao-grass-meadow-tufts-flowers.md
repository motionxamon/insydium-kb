# Быстрый луг из пучков травы и полевых цветов (Taiao Grass + пресет Grass Tuft + цветы из Preset Browser)

- Источник: Top Tip Tuesday — Taiao Grass Meadow — https://www.youtube.com/watch?v=6kNEj1CJbfQ (2023-05-02)
- Хост / поколение: C4D; Taiao (без частиц); материалы C4D
- Задача: реалистичный и лёгкий луг, инстансами на любом объекте-земле.

## Исходная сцена
tfTerrain с noise в виде холмистой земли, простой материал.

## Шаги
1. INSYDIUM ▸ Taiao ▸ **Taiao Grass**; укажите ландшафт как поверхность для генерации → сразу появляется **сплайновый слой травы**. Настройки слоя: плотность, тип Spline / **Polygons** (настраиваемые травинки) / инстансы своих объектов.
2. Реализм дают пучки из нескольких травинок: удалите сплайновый слой и возьмите пресет **Grass Tuft** (Taiao Plant с точкой роста + листьями в форме травинок).
3. Материалы пучка: бросьте в его список Materials два разных зелёных материала для вариации цвета.
4. Перетащите Grass Tuft в Taiao Grass как слой. На слое пучков: метод клонирования **Multi-Instances**, поднимите **Frequency**, **вариация масштаба ~10%**, поворот heading **360** + **вариация поворота 100%**, чтобы одинаковые пучки смотрели в разные стороны.
5. Цветы: **Taiao Preset Browser** ▸ Flowers ▸ **Buttercup**; перетащите как ещё один слой травы.
6. Разреживайте цветы на самом слое — **Frequency ~0.1%** (Global Density разредит и траву тоже); небольшая вариация масштаба; тот же трюк с heading 360 + 100%.
7. Повторите с **Daisy** (вариация масштаба + трюк с heading).

## Подводные камни
Global density влияет на все слои — каждый вид контролируйте через Frequency его собственного слоя.
