# Комнатная драцена (ветки Taiao Plant + сплайн модификатора Profile, Taiao Leaf, Redshift)

- Источник: INSYDIUM Official Training — Taiao Dragon Tree — https://www.youtube.com/watch?v=f6VqOjOtBH4 (2025-06-19)
- Хост / поколение: C4D; Taiao Plant / Leaf (модификаторы: Gravity, Profile, Fold, Turbulence, слои droop); Redshift
- Задача: растение в духе драцены — прямой ствол, две загнутые вверх ветки, основания листьев полумесяцем, длинные волнистые листья, засохшие нижние листья.

## Ствол и ветки
1. **Taiao Plant** ▸ Trunk: Height **30 cm**, Radius 2–3, почти прямой с лёгким сужением; Global Settings ▸ **Segment Resolution 0.5**; поднимите Ring Segments.
2. Добавьте **Branch**: отключите концевую ветку, Count **2**, Distribution **Spiral → Alternate**; добавьте точки на сплайн позиции, чтобы разместить ветки близко друг к другу у верхушки. Length ~25, небольшое сужение.
3. Branch Modifiers ▸ **Gravity** с **отрицательной силой** (можно ниже −100), чтобы ветки гнулись вверх; поднимите Weight, чтобы они выпрямлялись по длине; подстройте Angle.

## Черешки с профилем полумесяцем
4. Добавьте Branch на ветку: концевая ветка off, Count **10**, точками распределения сдвиньте их к верхушке; разведите по углу; расширьте тангенс профиля, чтобы у основания получилось утолщение. Ring segments **12** на обоих уровнях веток.
5. Сплайн Circle, Plane/axis **X**, сделайте редактируемым. Branch ▸ Modifiers ▸ **Profile**, закиньте туда сплайн; расставьте точки «улыбкой», чтобы основания обнимали родительскую ветку.
6. **Bias** у Profile: опустите конец и изогните кривую, чтобы перед листом форма возвращалась к круглому сечению.
7. Global Settings ▸ Subdivisions 1.
8. Два слоя droop/bend: первый стягивает черешки друг к другу (bias внизу); второй с **Blend Mode Add** отгибает их наружу; добавьте вариативность.

## Лист (Taiao Leaf)
9. Length **55**, segments **50 × 4**, Subdivision 1; сплайн профиля с двумя дополнительными точками для длинной пластины; **Edge Noise**; **Mid vein** с сужающимся профилем.
10. Modifiers ▸ **Fold** с множеством случайных узлов на сплайне → волнистая пластина; **Turbulence** Scale 350, Strength 70, Bias 10; ещё два слоя droop, чтобы приподнять кончики.
11. Черешок ▸ слой **Leaf**: count 0, **Leaf on End**, Geometry **Custom** = лист; масштаб + вариативность размера. Стык прячется уменьшением радиуса жилки, позиции листа и масштаба конца ветки.
12. Засохшие листья: скопируйте слой ветки-черешка через Ctrl-перетаскивание, удалите его слои droop, сдвиньте распределение ниже, добавьте новый слой droop вниз, Count 6, листья поменьше.

## Redshift
- Листья: legacy **RS Material** (ради контрового света/просвечивания): текстура листа → diffuse и translucency colour, weight 1; слабое отражение, высокая roughness. Коричневая копия для засохших листьев (второй слот материала листа).
- Ствол: RS Standard, отражение выключено, normal map в цветовом пространстве **Raw** → нода Bump Map в режиме **Tangent Space Normal**.
- Ветки: материал ствола смешан с зелёным через **Material Blender**, blend = инвертированный ramp с noise; зелёный subsurface. Черешки: зелёные с subsurface и небольшим отражением.
