# Основы Data Mapping: гравитация по возрасту/радиусу/яркости, циклические импульсы fuel/smoke в EFX (вкладка Mapping, Particle Console, Document Time + Cycle)

- Источник: NeXus for Blender Quick Guide — Data Mapping — https://www.youtube.com/watch?v=s5JA_AADBnY (2026-06-29)
- Хост / поколение: Blender (NeXus for Blender, G3): nxEmitter, nxCollider, nxGravity, nxExplosiaFX; вкладка Mapping у модификаторов
- Задача: процедурно анимировать параметры модификаторов для каждой частицы (возраст, радиус, цвет) или во времени — вместо ключей.

## Исходная сцена
- Эмиттер **Box**, birth rate 10 → 250, speed 0, radius **0.04 ±0.03**; отображение **Circle Filled**, режим цвета **Noise** с градиентом в зелёных оттенках.
- Большая скрытая плоскость как **nxCollider** (bounce 0, немного friction); **nxGravity** (по умолчанию 9.8).

## Шаги
1. Почему не ключи: если заключить гравитацию 0 → 9.8 (кадры 30 → 76), это влияет только на начало — частицы, рождённые позже, получают полную гравитацию. Удали ключи.
2. nxGravity ▸ **Mapping ▸ Add map ▸ Age** → параметр **Gravity Strength** (у этого модификатора есть только Strength или Variation). Диапазон **20 → 50 кадров**: гравитации нет, пока частице не исполнится 20 кадров, к 50 она выходит на полную и дальше остаётся полной. Каждая новая частица проигрывает это заново.
3. Как читать график: X = диапазон источника (min→max), Y = параметр от 0 до заданного значения.
4. Переключи источник на **Radius**: диапазон найди в **Particle Console** (колонка radius, min/max внизу) → **0.01 → 0.08**; крупные частицы падают быстрее, гравитация действует сразу.
5. Переключи источник на **Color Brightness**, диапазон **0 → 1**, на эмиттере градиент чёрный→белый: чёрные висят вечно, белые падают с полной гравитацией, серые — что-то среднее.
6. EFX: тор внутри более высокого **nxExplosiaFX**, добавлен как source; voxel size **0.02**; Simplex noise length scale **5**, strength **50**.
7. В EFX Mapping ▸ **Document Time** → параметр **Mesh (object) emission ▸ Fuel** (список параметров сгруппирован по типу источника: curve, particle, mesh). Рампа 20 → 50 кадров, или сделай из кривой пик = один взрыв.
8. Поведение конца кривой **Clamp → Cycle** повторяет взрыв; расширь диапазон до **0 → 70 кадров** и снизь эмиссию — получатся импульсы «взрыв, затем затухание».
9. Добавь постоянный **Smoke 2** на source, затем вторую карту Document Time для **Mesh Smoke** с обратной кривой (тоже на **Cycle**) → чередующиеся импульсы fuel / smoke.
10. Simulation ▸ **Burning ▸ Smoke Production off**, чтобы дым шёл только из замапленного канала.

## Подводные камни
- Новая карта остаётся на Clamp — ставь Cycle на каждом слое, который должен повторяться.
- Источники из данных частиц (age, radius…) бессмысленны для каналов EFX, излучаемых объектом; используй Document Time.

## Как сейчас (новые инструменты)
Бета 2026.1: один слой Mapping может управлять многими целями, плюс **nxFalloff Modifier** (Remap, Curve, Cycle, слои памяти) и falloff на каждый слой для пространственного контроля.
