# Обзор функций: слои nxSpin, Noise/Neighbor-градиент в nxColor, Direction Force в nxDirection (превью Fused 2025, часть 2)

- Источник: Fused 2025 Tech Preview — Modifier Improvements Part 2 — https://www.youtube.com/watch?v=QzIbDaoIH4Q (2025-07-24)
- Хост / поколение: C4D; GPU-модификаторы NeXus (nx…) на xpEmitters + инстансинг через xpGenerator; в последнем демо nxFluids PBD
- Статус: превью слоёных модификаторов, вошедших в **Fused 2025.4** (декабрь 2025)

## nxSpin (новый слоёный модификатор вращения)
- Слой **Spin**, Spin Time **On Birth**: Spin Amount 0 с **вариацией 360°** по всем осям = случайная начальная ориентация (инстансы спортивных мячей).
- Второй слой Spin, **Per Frame**: например, 10°/кадр по Bank; переключите Orientation **World → Particle**, чтобы крутить вокруг собственной оси каждой частицы. Amount 0 + вариация = случайные направление и скорость; небольшая вариация по другим осям добавляет покачивание.
- Слой **Range**: Spin Start → Spin End (0 → 360°) между кадрами Start/End (30 → 90), форма задаётся кривой ease; добавьте узел посередине, чтобы прокрутить туда и обратно; вариация по времени/значениям; **Cycle** для зацикливания. Небольшие значения по другим осям (20, var 10) для покачивания.
- Слой **Tangential**: выравнивает инстансы (ракеты) по направлению движения; выбор оси, смещение, вариация; опция **Spin** крутит их по Bank.

## nxColor
- Новый слой **Noise**: GPU-шумы INSYDIUM (FBM, Voronoise, Cubic…) управляют градиентом (по умолчанию чёрный→белый, чтобы управлять симуляцией; замените на heat-map для соответствующего лука). Быстрее, чем C4D Fields (CPU).
- **Gradient by Parameter ▸ Neighbor**: каждая частица считает соседей в радиусе (в демо 25 cm); ≥ максимального количества (3,000) = белый конец, ≤ минимального = тёмный. Плотное ядро против разреженных краёв; ступенчатый градиент даёт топографические полосы на жидкости.
- Зажатый neighbour-градиент = чёткая тёмная **маска поверхности/краёв** для таргетинга модификаторов (таяние, распад). Слои смешиваются: положите слой краёв в **Multiply** поверх цветового слоя, затем Noise-слой в Multiply с низкой силой для вариативности.

## nxDirection (теперь на слоях)
- Прежние режимы направления сохранены; новый слой **Direction Force** толкает частицы вдоль +Z объекта (Visible in Editor показывает стрелку; вращайте/анимируйте объект, чтобы рулить).
- **Twist Strength** 100% = против часовой, отрицательное значение (−200%) = по часовой; закрутка также выталкивает наружу, поэтому поднимите **Attract Strength** (300–400%), чтобы стягивать обратно к оси.
- Арт-директорский PBD-поток: Twist −100%, Attract ~250%, чтобы отрывались усики, плюс nxTurbulence для естественного течения; работает в реальном времени во viewport. Также рекомендуется для дыма/огня.
