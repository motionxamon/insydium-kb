# Пристыкованные палитры для инструментов INSYDIUM (C4D Command Manager, отрывные подменю, Lock Icon)

- Источник: Bite-Sized — Custom Tool Palettes — https://www.youtube.com/watch?v=jzFk-veno5U (2025-02-27)
- Хост / поколение: кастомизация интерфейса C4D (подходит для любого плагина)
- Задача: иконки в один клик (с выпадающими подменю) для NeXus, MeshTools, эмиттера и кэша.

## Шаги
1. **Window ▸ Customization ▸ Command Manager** ▸ **Edit Palettes** (палитры становятся редактируемыми).
2. Отдельные команды: поиск (например «nx» покажет все команды NeXus) и перетащите **nxFluids** в существующую палитру. В режиме редактирования двойной клик по иконке удаляет её.
3. Новая палитра: **New Palette**, затем тащите её за точечную ручку и пристыкуйте там, где появляется линия (например рядом со стандартными палитрами), а уже потом наполняйте.
4. Выпадающие группы: оторвите меню INSYDIUM (клик по его верхней полосе) и перетащите целое подменю — например **MeshTools** или X-Particles ▸ **NeXus** — в палитру; маленькая стрелка значит, что внутри подкоманды. Добавьте и частые одиночные элементы (**xpEmitter**, **xpCache**).
5. Порядок наводится **Group Separator** между наборами; можно по палитре на продукт (X-Particles, TerraformFX, Taiao…).
6. По умолчанию выпадающая иконка показывает последний использованный инструмент; выберите нужную иконку (например inset-иконку для MeshTools, nxAttract для NeXus), ПКМ ▸ **Lock Icon**.
7. ПКМ по пустому месту палитры — размер иконок, текст/текст под иконкой (съедает место), строки/столбцы.
8. Сохранить: Window ▸ Customization ▸ **Save as Startup Layout** или **Save Layout As** для выбираемой раскладки.

## Как сейчас (новые инструменты)
В NeXus 2026.1 меню Add разделено на Presets / Generators / Dynamics / Modifiers / Warps — эти подменю пристыковываются так же.
