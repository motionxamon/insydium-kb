# Пристыкованные палитры для инструментов INSYDIUM (C4D Command Manager, отрывные подменю, Lock Icon)

- Источник: Bite-Sized — Custom Tool Palettes — https://www.youtube.com/watch?v=jzFk-veno5U (2025-02-27)
- Хост / поколение: кастомизация интерфейса C4D (подходит для любого плагина)
- Задача: иконки в один клик (с выпадающими подменю) для NeXus, MeshTools, эмиттера и кэша.

## Шаги
1. **Window ▸ Customization ▸ Command Manager** ▸ **Edit Palettes** (палитры становятся редактируемыми). [▶ 2:12](https://youtu.be/jzFk-veno5U?t=132)
2. Отдельные команды: поиск (например «nx» покажет все команды NeXus) и перетащите **nxFluids** в существующую палитру. В режиме редактирования двойной клик по иконке удаляет её. [▶ 1:27](https://youtu.be/jzFk-veno5U?t=87)
3. Новая палитра: **New Palette**, затем тащите её за точечную ручку и пристыкуйте там, где появляется линия (например рядом со стандартными палитрами), а уже потом наполняйте. [▶ 2:51](https://youtu.be/jzFk-veno5U?t=171)
4. Выпадающие группы: оторвите меню INSYDIUM (клик по его верхней полосе) и перетащите целое подменю — например **MeshTools** или X-Particles ▸ **NeXus** — в палитру; маленькая стрелка значит, что внутри подкоманды. Добавьте и частые одиночные элементы (**xpEmitter**, **xpCache**). [▶ 4:09](https://youtu.be/jzFk-veno5U?t=249)
5. Порядок наводится **Group Separator** между наборами; можно по палитре на продукт (X-Particles, TerraformFX, Taiao…). [▶ 4:35](https://youtu.be/jzFk-veno5U?t=275)
6. По умолчанию выпадающая иконка показывает последний использованный инструмент; выберите нужную иконку (например inset-иконку для MeshTools, nxAttract для NeXus), ПКМ ▸ **Lock Icon**. [▶ 6:10](https://youtu.be/jzFk-veno5U?t=370)
7. ПКМ по пустому месту палитры — размер иконок, текст/текст под иконкой (съедает место), строки/столбцы. [▶ 7:11](https://youtu.be/jzFk-veno5U?t=431)
8. Сохранить: Window ▸ Customization ▸ **Save as Startup Layout** или **Save Layout As** для выбираемой раскладки. [▶ 7:43](https://youtu.be/jzFk-veno5U?t=463)

## Как сейчас (новые инструменты)
В NeXus 2026.1 меню Add разделено на Presets / Generators / Dynamics / Modifiers / Warps — эти подменю пристыковываются так же.
