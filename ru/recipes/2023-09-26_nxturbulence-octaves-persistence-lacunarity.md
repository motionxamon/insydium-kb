# Крупные завихрения плюс мелкая детализация (nxTurbulence Voronoi, Octaves, Persistence, Lacunarity)

- Источник: Top Tip Tuesday — nxTurbulence Octaves — https://www.youtube.com/watch?v=_q9xeElfTfI (2023-09-26)
- Хост / поколение: C4D; G2 NeXus внутри X-Particles (nxTurbulence — управление не такое, как у CPU xpTurbulence)
- Задача: сохранить крупное закручивающееся движение от базового шума и добавить анимированную мелкую детализацию от высших октав.

## Исходная сцена
Два эмиттера: короткоживущие частицы, окрашенные по направлению (2D-визуализация шума), и тонкий эмиттер, показывающий движение в 3D.

## Шаги
1. Тип шума **Simplex → Voronoi** → крупные завихрения. Если уменьшить масштаб шума, получится мелкая детализация как у пламени, но завихрения пропадут. [▶ 3:12](https://youtu.be/_q9xeElfTfI?t=192)
2. Возвращаем scale на **100**; **Octaves 1 → 10**. [▶ 3:38](https://youtu.be/_q9xeElfTfI?t=218)
3. **Persistence** (по умолчанию 100% = одинаковая сила во всех октавах): уменьшаем, чтобы доминировала первая октава; затем поднимаем ровно настолько, чтобы сохранилась часть мелкой детализации. [▶ 3:04](https://youtu.be/_q9xeElfTfI?t=184)
4. **Frequency** (100) анимирует шум; 0 = статика. [▶ 3:38](https://youtu.be/_q9xeElfTfI?t=218)
5. **Lacunarity**: при 0 анимируется только первая октава (высшие заморожены). Поднимаем до **~2.3** → анимируются все октавы; чуть меньше — крупные завитки спокойнее. [▶ 3:31](https://youtu.be/_q9xeElfTfI?t=211)
