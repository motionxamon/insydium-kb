# Обзор функций: Advanced Terrain Shader в TerraformFX (TerraformFX 2024.2)

- Источник: TerraformFX Sneak Peek – Advanced Terrain Shader, Release Update Coming Soon 2024.2 — https://www.youtube.com/watch?v=SYYZL_rJ3cc (2024-04-18)
- Хост / поколение: C4D; TerraformFX (операторы tfTerrain); шейдер работает в любом рендере, поддерживающем шейдеры C4D
- Статус: превью **Fused 2024.2** (9 мая 2024)

## Что делает
Новые террейны идут с материалом, в канале Color которого стоит **Advanced Terrain Shader**: он смешивает каналы данных террейна в чёрно-белые карты и раскладывает по ним цветовые палитры. Виден во viewport.

## Слои и параметры
- **Terrain Layer**: смешивает каналы данных — **Altitude**, **Curvature**, **Ambient Occlusion**, плюс крупный и мелкий noise и Jitter → ч/б карта; включите раскраску палитрой, чтобы наложить на неё цвета.
- Слои **пост-обработки**, например **Normalize** (полный диапазон цветов), **Curves** (контраст) и Jitter.
- **Палитры**: Surfaces (песок, камень, лава…) или **Countries** — глобальный список, каждая палитра снята с реальных спутниковых снимков (в демо — Германия для травы).
- **Маскирование**: слой-маска как **дочерний** к цветовому слою (белое = виден верхний слой, чёрное = нижний); **Preview Current Layer**, чтобы посмотреть одну карту.
- **tfFlood** выдаёт flood mask и difference map; **Add Flooded Layer** автоматически создаёт в шейдере цвет воды + маску.
- Слой **Agricultural Structures**: поля сеткой или случайно, количество, размер, нерегулярность, **борозды** (линии вспашки/посевов), грунтовые дороги между полями.
- Слой-маска **Terrain Operator**: подключите террейн или любой оператор и маскируйте по его данным (Altitude, Slope) с инвертированными кривыми gradation → поля только в низких ровных местах.
- **Bake/экспорт** в любом разрешении: вся текстура, все слои или выбранные слои, TIFF 8/16/32 бит.

## Как сейчас (новые инструменты)
Это по-прежнему способ текстурирования в TerraformFX для Fused 2025.4. В Redshift для C4D 2024+ поднимите размер запекания по умолчанию 128×128 для шейдеров TerraformFX. См. «TerraformFX height map Redshift displacement» (2025-02-04).
