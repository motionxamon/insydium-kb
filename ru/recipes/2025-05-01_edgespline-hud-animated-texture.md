# Анимированные HUD-линии сканирования из текстуры (mtEdgeSpline Texture Tag mapping, Planes, Dashes)

- Источник: Bite-Sized — EdgeSpline HUD — https://www.youtube.com/watch?v=LTAiSYatydQ (2025-05-01)
- Хост / поколение: C4D; MeshTools **mtEdgeSpline** (без частиц); Redshift для исходного скана
- Задача: превратить анимированную текстуру в канале Luminance в мерцающую многослойную HUD-графику из сплайнов.

## Исходная сцена
Plane со стандартным материалом, в канале **Luminance** — анимированная текстура (в демо — фейковый МРТ-скан, сделанный через **Clipping Plane** камеры Redshift, которую проводят сквозь объект). Когда текстура готова, plane скрываем.

## Шаги
1. Новый **Plane** как входной mesh; Width/Height Segments поднять до ~80–90 для детализации. [▶ 0:41](https://youtu.be/LTAiSYatydQ?t=41)
2. INSYDIUM ▸ MeshTools ▸ **mtEdgeSpline**, plane — дочерним → сплайны по рёбрам квадов. Выключить отображение градиента и скрыть mesh. [▶ 0:51](https://youtu.be/LTAiSYatydQ?t=51)
3. Вкладка Object ▸ Mapping ▸ **Texture Source: Texture Tag**, кинуть туда тег текстуры исходного plane (его проекция используется как есть). [▶ 1:18](https://youtu.be/LTAiSYatydQ?t=78)
4. Канал переключить с Color (по умолчанию) на **Luminance** → остаются только рёбра там, где текстура светлая, и скан бежит по сплайнам. [▶ 1:44](https://youtu.be/LTAiSYatydQ?t=104)
5. Подстроить **Tolerance** (сколько информации проходит), **Growth** (проявление результата волной) и его offsets. [▶ 1:59](https://youtu.be/LTAiSYatydQ?t=119)
6. **Planes**: только U / только V дают линии скана в одном направлении; Combined = сетка. Offsets растягивают линии; включить **dash lines** для штриховки / перекрестий. [▶ 2:26](https://youtu.be/LTAiSYatydQ?t=146)
7. Слои: продублировать сетап, отмасштабировать/сдвинуть базовый plane, сменить цвет (синий, затем красный), уменьшить число сегментов, варьировать dash/plane для каждой копии — каждый слой мерцает по-своему. [▶ 2:57](https://youtu.be/LTAiSYatydQ?t=177)

## Подводные камни
- Мало сегментов у входного plane = грубая, блочная реакция сплайнов.
