# Динамичный 2D-эффект карандашного скетча на анимированном персонаже (mtEdgeSpline режим Outline)

- Источник: Top Tip Tuesday — MeshTools Sketch Mouse — https://www.youtube.com/watch?v=tApA-55P7FM (2023-05-16)
- Хост / поколение: C4D; MeshTools (без частиц); стандартный вьюпорт/рендерер
- Задача: зависящий от камеры контур + штриховка, которые следуют за ригованной 3D-моделью.

## Исходная сцена
C4D Asset Browser ▸ Example Scenes ▸ Character Animation ▸ сцена с ригованной **Mouse** (камера/свет удалены, контроллеры рига скрыты).

## Шаги
1. INSYDIUM ▸ MeshTools ▸ **mtEdgeSpline**; сделайте мышь его дочерним объектом. Режим по умолчанию **Standard** = сплайн на каждое ребро полигона (хорошо для HUD/FUI-стилистики).
2. Режим **Curvature**: Curvature Angle 0 = то же, что Standard; поднимите, чтобы сплайны остались только на изогнутых участках (статично, не зависит от вида).
3. Режим **Outline**: сплайны идут по силуэту относительно камеры и обновляются при движении камеры или рига.
4. 2D-подача: C4D **Sky** с Basic ▸ display color, свой белый; мыши — белый материал только с luminance; цвет сплайна mtEdgeSpline → угольно-серый.
5. Поднимите **Outline Angle** → штрихи заползают внутрь, как тени.
6. Перекрёстная штриховка: **Start Offset / End Offset ≈ 0.05 cm** (модель крошечная), чтобы штрихи выходили за края и пересекались.

## Подводные камни
Offset задаются в единицах сцены — масштабируйте их под размер модели.
