# Рост слизевика по бревну (mtRemesh + mtShortestPath + xpSplineMesher)

- Источник: Bite-Sized — MeshTools Slime Mold — https://www.youtube.com/watch?v=POC6gx3p4rc (2025-09-18)
- Хост / поколение: C4D; MeshTools (**mtRemesh**, **mtShortestPath**) + CPU **xpSplineMesher** (X-Particles Generators)
- Задача: органичные растущие прожилки слизевика, расползающиеся из одной точки по части меша.

## Шаги
1. Дублируем бревно (Ctrl-перетаскивание), оставляем только ту полигональную выделенную область, где должен расти слизевик (инвертируем выделение, удаляем). Оставляем меш **триангулированным** — треугольники дают органичные пути, квады — сеткоподобные.
2. **mtRemesh** (триангуляция Делоне): **Feature angle 180°** (следовать поверхности), **Edge length ~0.3** для плотной сети треугольников. Делаем editable, выкидываем null.
3. Выбираем одну вершину во влажной расщелине ▸ Select ▸ **Set Selection** = стартовая точка.
4. **mtShortestPath** ▸ Objects: ремешнутый кусок; Start = **Source** → тег выделения точек.
5. **End number** = сколько точек охватывает сеть: **800** для работы, ~5,000 чтобы покрыть весь меш; при анимации это выглядит как рост. Отключаем отображение стартовой/конечной точек.
6. Сплайн: **Linear → B-Spline**, Intermediate points **Uniform** → плавные кривые.
7. **xpSplineMesher** с объектом shortest-path в качестве источника: выключаем **joins**, **size 2**, **subdivisions 2** (круглое сечение вместо квадратного).
8. Size ▸ **Scale spline**: добавляем горб на одном конце для вздутых кончиков.
9. Анимируем слайдер **Growth** у мешера для ползущего проявления. Опционально: Displacer для пузырчатой поверхности.
