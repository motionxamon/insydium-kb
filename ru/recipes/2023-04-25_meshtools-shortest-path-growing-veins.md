# Процедурно растущие вены на модели (MeshTools Remesh + mtShortestPath + xpSplineMesher)

- Источник: Top Tip Tuesday — MeshTools Veins — https://www.youtube.com/watch?v=_03xlveAuZ4 (2023-04-25)
- Хост / поколение: C4D; MeshTools + генератор X-Particles **xpSplineMesher** (CPU, без частиц)
- Задача: сужающиеся вены, которые прорастают по мешу от одного или нескольких корней.

## Шаги
1. Ctrl-перетаскиванием сделайте копию модели, оригинал скройте. INSYDIUM ▸ MeshTools ▸ **Remesh** с копией в качестве дочернего объекта → треугольники (вены текут лучше); нажмите **C**, чтобы сделать редактируемым.
2. MeshTools ▸ **mtShortestPath**, треугольный меш дочерним объектом. Вкладка Display ▸ показать **start/end points** (размер побольше): одна случайная синяя стартовая вершина, случайные красные конечные; пути идут по рёбрам от старта к концам.
3. Вкладка Object: **End count 500**. Отображение точек скройте.
4. Анимация: включите **Custom Growth Rates** + вариацию, чтобы каждый путь рос со своей скоростью; включите **Avoid**, чтобы пути не перекрывались.
5. Опционально для контроля: положите point selection tag в **Source**, чтобы выбрать стартовые точки.
6. INSYDIUM ▸ X-Particles ▸ Generators ▸ **xpSplineMesher**: Joins выкл., vertex colors выкл.; привяжите mtShortestPath. Скройте путь, покажите оригинальную модель.
7. Size **2–3 cm**; откройте кривую Size и опустите конец в 0, чтобы вены сужались в точку. Красный материал на мешер.
8. Обратный рост: mtShortestPath **Invert** — затем отразите кривую размера мешера (выделите обе точки ▸ **Flip Horizontal**), чтобы сужение по-прежнему смотрело в нужную сторону.
9. Больше корней: **Start count 4** → пути пересчитываются от четырёх корней; они деформируются вместе с анимированной геометрией.

## Подводные камни
Пути можно рендерить и напрямую как светящиеся шлейфы (FUI-лук), без меширования.
