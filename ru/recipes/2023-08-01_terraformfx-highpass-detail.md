# Детализация камнями и трещинами без изменения силуэта ландшафта (tfGroup + фильтр High Pass)

- Источник: Top Tip Tuesday — TerraformFX HighPass — https://www.youtube.com/watch?v=di7_ZIst1Ws (2023-08-01)
- Хост / поколение: C4D; TerraformFX (tfTerrain, tfGrid, tfWarp, tfNoise, tfGroup, фильтр High Pass)
- Задача: сохранить точно подогнанную форму холма на заднем плане (например, по плейту) и добавить поверх только высокочастотную пустынную детализацию.

## Исходная сцена
tfTerrain, вылепленный с помощью **tfGrid** + **tfWarp**, — форма, которую менять нельзя.

## Шаги
1. Проблема: tfTerrain ▸ Add Operator ▸ **tfNoise** (переключён на «клубящийся» тип, больше октав, ниже Blend) добавляет детали, но сдвигает общую высоту — включите/выключите его, чтобы увидеть. [▶ 1:04](https://youtu.be/di7_ZIst1Ws?t=64)
2. Add Operator ▸ **tfGroup**, положите noise внутрь (группа включает/выключает всё, что под ней). [▶ 2:01](https://youtu.be/di7_ZIst1Ws?t=121)
3. Внутри группы добавьте фильтр **High Pass** → от noise остаётся только высокочастотная часть; переключение группы больше не меняет силуэт. [▶ 2:31](https://youtu.be/di7_ZIst1Ws?t=151)
4. **Radius** у High Pass: маленький — только самые мелкие детали; больше — пропускает больше частот; **100** ≈ фильтра нет (и медленно). В демо было **26.5**, затем амплитуду/gain noise уменьшили, чтобы пики не поднимали ландшафт. [▶ 3:17](https://youtu.be/di7_ZIst1Ws?t=197)
5. Трещины: вторая **tfGroup** с **tfNoise** в режиме **Voronoi**, Scale **~20**, Gain оператора **~10**, **Invert** в свойствах, плюс свой **High Pass** → сеть трещин. Gain **20** — для более глубоких трещин. [▶ 5:09](https://youtu.be/di7_ZIst1Ws?t=309)
6. Замаскируйте группу трещин по **Altitude** (только ниже **20 cm**), чтобы трещины были в низинах. [▶ 5:42](https://youtu.be/di7_ZIst1Ws?t=342)
7. Если отключить обе группы, вернётся точная исходная форма. [▶ 6:00](https://youtu.be/di7_ZIst1Ws?t=360)

## Подводные камни
- Большие радиусы high-pass дорого считаются.

## Как сейчас (новые инструменты)
То же самое в Fused 2025.x; **Advanced Terrain Shader** и канал кривизны из Fused 2024.2 позволяют текстурировать новую детализацию. В Redshift (C4D 2024+) поднимите разрешение запекания шейдеров TerraformFX выше дефолтных 128×128.
