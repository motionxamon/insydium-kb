# Формируем частицы, дым и FLIP варпами (nxWarp Scroll / Bend / Helix / Twist — режимы Deform, Guide, Flow)

- Источник: NeXus Official Training — nxWarps — https://www.youtube.com/watch?v=WJwIek6M8z8 (2026-10-30)
- Хост / поколение: C4D (части 1–2, cm) и Blender (части 3–4, m); NeXus 2026.1 beta (G3: nxEmitter, nxWarp, nxExplosiaFX, nxFluids FLIP, nxMesher)
- Задача: точно и процедурно придать форму шумным симуляциям — свернуть 2D-поток в 3D-волну, провести поток по «трубе», согнуть/закрутить огонь, закрутить спиралью FLIP-струю.

## Основы варпов (на плоскости, C4D)
- Сделайте варп дочерним к геометрии и нажмите **Fit to Parent**, чтобы границы совпали. Работает недеструктивно, как деформер в C4D/Blender.
- **nxWarp Scroll**: Roll, Radius, Spacing (зазор между витками), Direction (отрицательное = закрут, как у разбивающейся волны).
- У всех варпов есть общие **Twist**, **Taper** (спереди/сзади), **Bulge** + **Position**.
- Три режима: **Deform** (двигает только отображаемые позиции, симуляция не трогается), **Guide** (управляет самой симуляцией; **Guide Strength**), **Flow** (держит частицы внутри профиля, пока они не выйдут через торец).

## Шаги
1. **2D-сим → 3D-волна (C4D):** nxEmitter сплющен (высота почти 0), стоит у задней стороны варпа; Birth Rate 50,000 (потом 150,000); размер в Display 2; Full Lifespan выкл., Life 100, вариация 20.
2. **nxTurbulence** (нойз Voronoi по умолчанию выглядит как пламя): Axis Direction Scale **Y = 0**, чтобы оставить плоским; Octaves 3; снизьте Persistence, чтобы сохранить крупные завихрения.
3. **nxWarp Scroll** по размеру так, чтобы охватить все частицы (тяните за хэндлы); Radius 8, Spacing 1, потом увеличьте Radius и Roll; отрицательный Direction. По желанию: масштаб по Y 15–40% для глубины, затем поднимите высоту варпа (по умолчанию 1 cm), чтобы всё влезло. **nxColor** — градиент по Speed.
4. **Поток по трубе (C4D):** Disc-эмиттер r 15 cm, rate 15,000, life 300, + nxTurbulence + nxColor. **nxWarp Bend** повернуть на 90° навстречу потоку, Angle 90°.
5. **Режим Guide**: частицы реально проходят изгиб. При 100% strength турбулентность сглаживается; снизьте для детализации, но при слишком низком значении частицы вылетают за границы.
6. **Режим Flow**: Profile Square (по умолчанию) / Circle (трубка) / Star / Custom (управляющий сплайн); выйти частицы могут только через выходной торец.
7. Ctrl-drag копию, поверните на 180° и 90° → S-образный изгиб. Добавьте куб + **nxCollider** (scatter) после выхода: коллизии работают в режиме Guide, а в Deform нет (частиц там на самом деле нет).
8. **nxGravity** с небольшим **Linear falloff** у выхода трубы, чтобы гравитация включалась только после направляющей; у коллайдера Bounce 0, больше Friction/Scatter.
9. **Огонь (Blender):** nxExplosiaFX, сфера во вкладке Sources, воксель покрупнее, Temperature Dissipation 3. Границы варпа = домен или чуть больше. Bend 90/180/360°; Twist ~800°.
10. **Helix**: Start Radius 0, Mid 0.5, End 1.5, Turns 3. Варпы можно наслаивать: скопируйте helix, переключите копию на Bend, увеличьте её границы, чтобы охватить уже деформированный дым, Angle 180–360°.
11. Режим Guide на дыме управляет реальной симуляцией, но сглаживает её и не выходит за домен — ставьте низкий Guide Strength, чтобы сохранить огненную детализацию.
12. **FLIP-спираль (Blender):** высокий домен nxFluids FLIP; сферический nxEmitter внизу, **Match Solver Resolution** → FLIP, направление +Z, скорость 2.5; nxColor по Speed; nxTurbulence strength 16.
13. Модификатор типа аттрактора с целью вверху: Acceleration 0, Speed Limit огромный, Force 20 — держит тонкую струю. У FLIP **стенка +Z = Kill**.
14. **Mapping** ▸ слой Particle Age → **Strength** турбулентности: полная до возраста 100, затухает примерно до 0 к 200.
15. **nxWarp Twist** вокруг всей колонны, режим Guide, Angle 500 → 2000 с пониженным Guide Strength; поднимите силу аттрактора, чтобы удержать струю.
16. Слой эмиттера в **nxMesher**: Resolution 0.02, Radius 0.03–0.04 (0.025 слишком тонко), Surface **Zhu-Bridson**.

## Подводные камни
- Границы варпа должны охватывать все частицы/воксели; для наслоенного варпа подгоняйте их под результат предыдущего варпа.
- Deform — быстро и точно, но не физично; Guide/Flow — физично, поэтому коллайдеры и силы дальше по цепочке работают корректно.
- В Beta 3 (вышла в тот же день) **Flow Reach** по умолчанию стал 0% — для старого поведения Flow ставьте 300%.
