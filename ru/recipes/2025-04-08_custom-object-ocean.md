# Анимированная поверхность океана внутри любого объекта (xpOcean Deformer + Boole Intersect, с зацикливанием)

- Источник: Top Tip Tuesday — Custom Object Ocean — https://www.youtube.com/watch?v=r_AyI7Bgi0U (2025-04-08)
- Хост / поколение: C4D; CPU X-Particles **xpOcean** (Generators) + C4D Boole; Standard material с Fresnel
- Задача: «море», заполняющее логотип / 3D-текст (здесь буква X), с бесшовным зацикливанием.

## Исходная сцена
Text object "X"; плоскость **250×250 см, 300×300 сегментов** (плотнее = больше деталей в волнах, но медленнее).

## Шаги
1. **xpOcean** ▸ режим **Deformer** (не Primitive), дочерним к плоскости.
2. Внешний вид: **Wave Height 8**, **Ocean Size 250**, **Smallest Wave 0.1** (по умолчанию 1 — меньшее значение добавляет мелкие детали), скорость ветра чуть ниже, немного **Damping** (0 = волны просто плещутся туда-сюда, 1 = полностью следуют направлению ветра).
3. **Choppiness ≈ 1** — заостряет гребни и растягивает впадины; слишком большое значение заворачивает меш.
4. Поставьте плоскость там, где поверхность должна разрезать X. **Boole**: дочерние текст + плоскость, режим **Intersect**, **Remove Self Intersections off** (быстрее), **High Quality Normals on** (убирает артефакты шейдинга).
5. Зацикливание: xpOcean ▸ **Looping on**, Loop Time = последний кадр + 1 (**201** для сцены на 200 кадров).

## Подводные камни
- Любое заворачивание меша от choppiness ломает Boole — на этих кадрах результат пропадает. **Проскрабьте весь таймлайн** (например, при слишком высоком значении всё ломалось около F167) перед запеканием/рендером.
- Boole пересчитывается каждый кадр → медленное воспроизведение; при необходимости запеките.

## Как сейчас (новые инструменты)
В 2026.1 beta есть **nxOcean** — GPU-океан (спектры, пена, брызги, береговые линии, связка с FLIP), но в whats-new не указан режим деформера для произвольных мешей — для такого трюка с логотипом документированным способом остаётся CPU xpOcean в режиме Deformer.
