# Геометрический «органический» рост из стопки инсетов (слои MeshTools mtInset + анимированное сферическое поле)

- Источник: Top Tip Tuesday — Inset Growth — https://www.youtube.com/watch?v=1KQjzMfJXRw (2024-11-26)
- Хост / поколение: C4D; **MeshTools** (mtInset), Redshift Sun
- Задача: шот из рекламы Black Friday 2024 — плотные узоры инсетов, расползающиеся по изогнутой панели.

## Исходная сцена
Плоскость 800×950 с деформером Wrap (сферический изгиб) + Displacer (анимированный noise).

## Шаги
1. Alt-клик по **mtInset** на плоскости: amount **100%** + небольшой offset (триангулированный, «проколотый» вид). [▶ 1:27](https://youtu.be/1KQjzMfJXRw?t=87)
2. Через Alt вложите ещё один mtInset: amount анимирован 40 → 60 %, offset для бликов на рёбрах. [▶ 2:20](https://youtu.be/1KQjzMfJXRw?t=140)
3. Следующий: статичный 45 %, offset 1.
4. Следующий: широкая анимация 20 → 80 %, offset 1, ограничен **Spherical field**; анимируйте размер поля наружу (100 → больше). [▶ 3:25](https://youtu.be/1KQjzMfJXRw?t=205)
5. Продолжайте наращивать стопку (45 %, 46 %, 48 %, offset 1), каждый с тем же полем → плотная детализация растёт вместе с полем. [▶ 3:59](https://youtu.be/1KQjzMfJXRw?t=239)
6. Рендер с анимированным **Redshift Sun**: множество рёбер ловят тени и блики; простой отражающий материал. [▶ 5:38](https://youtu.be/1KQjzMfJXRw?t=338)
