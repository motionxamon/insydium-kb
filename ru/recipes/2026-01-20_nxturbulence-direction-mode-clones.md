# Колышущееся поле клонов: режим nxTurbulence "Direction" + nxSpin Tangential + nxLimit

- Источник: Top Tip Tuesday — Turbulence Direction — https://www.youtube.com/watch?v=HUTvETBii0k (2026-01-20)
- Хост / поколение: NeXus (Fused 2025.4+: режим Direction, слоёные модификаторы, GPU-falloff) + xpGenerator Multi-Instance
- Задача: 40 k тонких столбиков на плоскости, которые колышутся, как водоросли/мех, не сдвигаясь с места.

## Объект для инстансов
Cube X/Z 5 cm, высокий → make editable → **Axis Center** Y −100 (пивот у основания) → включите режим Axis, поверните так, чтобы **ось Z смотрела вверх** (90°, Shift — шаг 5°).

## Стек (порядок важен)
1. **nxSpin** (наверху): слой **Tangential**, axis Z → частицы ориентируются по своей скорости/направлению.
2. **nxTurbulence**: режим **Direction** (вместо Acceleration) → шум вращает частицы, а не двигает их. Слой **Curl**, Scale побольше, Frequency пониже; Octaves ↑ при **Persistence ↓** → крупные завихрения сохраняются плюс немного мелкой детали.
3. **nxLimit** (последним): слой **Rotation**, Relative; ограничьте **Pitch** +90 / −90 (не заваливаются ниже плоскости; ±45 — не ложатся плашмя), heading свободен; добавьте вариацию.
4. **xpGenerator** Multi-Instance со столбиком в качестве дочернего объекта; вариация радиуса эмиттера → разброс размеров.

## Интерактивная волна
Вкладка Falloff в nxTurbulence: falloff **Sphere**; анимируйте его через поле → по нему проходит рябь. Поднимите нижний край сплайна falloff до ~0.5 → лёгкое движение везде, полный эффект внутри.
