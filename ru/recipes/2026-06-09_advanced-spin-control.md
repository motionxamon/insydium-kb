# Случайная ориентация при рождении + повторяемые обороты на 360° (nxSpin + сброс возраста)

- Источник: Top Tip Tuesday — Advanced Spin Control — https://www.youtube.com/watch?v=I98idMM1O80 (2026-06-09)
- Хост / поколение: NeXus (слои nxSpin, nxQuestion) + xpGenerator (футбольные мячи), C4D
- Задача: инстансированные мячи стартуют со случайной ориентацией, а затем делают ровно один полный оборот каждый раз, когда пульсируют, увеличиваясь в размере.

## Настройка
1. Радиус частиц пульсирует через nxQuestion Wave (см. «Sine Wave Action»).
2. **nxSpin «Spin Birth»** (внизу): слой **Spin**, Spin Time **On Birth**, вариация Heading 360°, небольшая вариация по P/B → только случайная начальная ориентация.
3. **nxSpin «Spin Animation»**: слой **Range**, Orientation **Particle**, Start 0 → End 360° (heading), время Start/End 0–60 (или 68) кадров; сдвиньте узел кривой, чтобы задержать старт. Добавьте вариацию вращения (50°) и вариацию времени, чтобы мячи не останавливались одновременно.
4. Зацикливаем range: **nxQuestion** `If Radius < 36.5 → Set Age = 0`. Пока частица маленькая, её возраст держится на 0; когда она большая, возраст идёт и Range-вращение проигрывается один раз; следующий пульс сбрасывает его.
5. Порог найдите через **xpConsole** (Utilities): Data to display → Radius; двойной клик → min/max (здесь минимальный большой радиус ≈ 36.4).

## Примечания
- Отдельные объекты nxSpin для ориентации при рождении и для анимации.
- Слой Spin с ориентацией Particle + amount 0 / variation 360 = случайные скорости в обе стороны.
- Трюк со «сбросом возраста» работает для любого слоя Range (nxScale, nxColor, nxSpeed), чтобы зациклить его по событию.
