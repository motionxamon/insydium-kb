# Обзор функций: GPU nxExplosiaFX (Fused 2025 Tech Preview)

- Источник: Fused 2025 Tech Preview — NeXus ExplosiaFX — https://www.youtube.com/watch?v=ePQeDy7XXlc (2025-10-16)
- Хост / поколение: C4D; NeXus GPU **nxExplosiaFX** (превью до релиза; вышел в Fused 2025.4, декабрь 2025) + Redshift для рендера
- Заменяет: CPU **xpExplosiaFX** + Source-теги на каждом объекте + правки в настройках проекта — теперь всё собрано в одном объекте.

## Структура
- **Вкладка Object**: горение, диссипация, плавучесть, диффузия, апскейл, слои **Forces**. Вкладки **Sources**, **Dynamics** (Colliders, Modifiers, Particle Advection), **Mapping**, **Display**.

## Sources (сколько угодно, без тегов)
- Полигональные объекты (Surface / Volume), сплайны, xpEmitter'ы (например, Pulse) — всё в одном списке, у каждого типа свои настройки. Передача **Velocity** объекта (например, 200%).
- Для каждого канала (Smoke, Temperature, Fuel, Pressure): **Weight by** None / **Tag** (vertex map, можно анимировать) / **Noise** (GPU-нойзы INSYDIUM: strength, length scale, frequency; CPU-шейдеры тоже можно).
- **Mode** канала: Set (по умолчанию, количество за кадр), Blend (несколько перекрывающихся источников), **Add / Subtract per second** — например, Volume-сфера в режиме вычитания дыма вырезает дыру (меньше значение = мягче затухание).
- **Fuel / Pressure frame limit**: быстрые взрывы без ключей (в демо: 3 кадра топлива, 10 кадров давления на 500 → взрыв отскакивает от пола).

## Настройки симуляции
- Горение (только топливо): **Ignition temperature 600** по умолчанию (0 = топливо воспламеняется само), **Burn rate** (упирается в потолок, когда всё топливо сгорает за кадр), **Temperature production**, **Smoke production** (густой дым + низкая температура могут задушить пламя), **Gas expansion** (~85 = большой резкий взрыв).
- **Diffusion** по каналам (temperature ~100 → мягкое пламя, как у свечи), **Dissipation** по каналам (ниже диссипация температуры = выше пламя), **Buoyancy** по каналам — сильно отрицательная плавучесть дыма + быстрая диссипация температуры = оседающий дым, как от сухого льда.
- Уровни **Upscaling** (1 = выкл.): апсемплит температуру и дым поверх базовой скорости → то же движение и форма, гораздо больше детализации, экономно по VRAM.

## Адвекция частиц (Dynamics ▸ Particle Advection)
- **Advect particles**, velocity strength 100%; также можно адвектить каналы **smoke, temperature, fuel, color** в данные частиц.
- Применение: красить частицы по температуре (в эмиттере Display ▸ Gradient by parameter); nxQuestion age > 30 AND smoke < 0.1 → Kill (+ вариация), чтобы частицы гасли вместе с дымом.
- Mapping ▸ сила Particle Advect по **Age** (полная до 40, ноль к 50) — искры отрываются от потока.

## Коллайдеры (Dynamics ▸ Colliders)
- Перетащите объекты; **Velocity scale** (100% по умолчанию, 500% для стилизованных толчков); **Pressure** коллайдера (600–1000) отталкивает флюид от поверхности; **Inside normals** запирает симуляцию внутри меша (например, спиральная Sweep-трубка).

## Forces (слои, во вкладке Object)
- Несколько слоёв **Vorticity / Turbulence / Wind**. Vorticity усиливает уже существующие завихрения (слишком много = дым как вата); у каждого слоя встроенный маппинг силы (smoke/temperature/fuel, скорость, время, **Position Y** 0–1 в сетке). В демо: Vorticity 20+ с маппингом «сильнее внизу» + второй слой без маппинга ~4.7.
- Turbulence добавляет движение: тип GPU-нойза (Simplex), length scale (~370 в демо), frequency, **Octaves** (0 = крупные мягкие порывы, детали оставьте vorticity).
- Встроенный слой **Wind** (по умолчанию +Z) с перемещаемым объектом ветра, силой и вариацией.

## Вкладка Mapping
- Маппинг силы эмиссии для источников-частиц / сплайнов / мешей, модели горения и адвекции на данные частиц или **сцены** (время документа). Пример: топливо нарастает на F30–60, превращается в импульс, **Cycle** — для повторяющихся вспышек.

## Модификаторы NeXus (Dynamics ▸ Modifiers)
- Перетащите nx-модификаторы: **nxAttract** направляет шлейф (поднимите vorticity/turbulence, чтобы вернуть детали); **nxWind Von Karman** для порывов (friction velocity, turbulent strength), согласованно работает и с отдельными симуляциями частиц.

## Display
- По умолчанию во вьюпорте **Volume ray marching**: ray max steps, ambient light (heading, pitch, tint); у дыма extinction (~100), tint, **albedo**, **anisotropy** рассеяния (ореолы в контровом свете); у огня **hot soot intensity** + **hot gas intensity** (Blackbody или ручной цвет, например, синее газовое пламя).
- Диагностика: **Volume slicing** по каналам, режим **Speed** (показывает максимальную скорость — ориентир для маппинга); HUD: воксельная сетка, **adaptive bounds**, velocity trails.
