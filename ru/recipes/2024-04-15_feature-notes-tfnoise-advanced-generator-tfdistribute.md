# Обзор функций: генератор Advanced Noise в tfNoise и tfDistribute (TerraformFX 2024.2)

- Источник: TerraformFX Sneak Peek – Release Update Coming Soon 2024.2 — https://www.youtube.com/watch?v=qBAJGCLYdQo (2024-04-15)
- Хост / поколение: C4D; TerraformFX (операторы tfTerrain)
- Статус: превью **Fused 2024.2** (9 мая 2024)

## tfNoise ▸ генератор Advanced Noise (старые шумы Maxon по-прежнему доступны)
- Базовый **Noise Type** (смещение/масштаб), затем:
  - **Fractal sampling** добавляет деталей: **FBM** (скалистый), **Billow**, **Ridged** (острые пики); меньше Octaves → возврат к базовому шуму.
  - **Warping** искажает базовый шум тоже через fractal sampling; Strength даёт скалистые зоны против ровных лугов. Fractal + warp вместе = размытые каньоны.
  - Вторая опция warp искажает ещё и фрактал, используемый в сэмплинге (сильно = завихрения, слабо = мягкая форма рельефа).
- Тип **Cellular**: Jitter (формы Voronoi); Return Type **Distance** + фрактальный warp = крупные детализированные дюны; другие return type = скальные образования или мощение; перебирайте seed.
- Типы **Macro** (мало параметров, быстрые ландшафты): **Prairie** и **Mixed Macro**.
- Тип **Gabor**: нестандартные поверхности (луна, текстуры камня).
- Каждый пример — один tfNoise; можно смешивать с остальными операторами TerraformFX.

## tfDistribute (новый фильтр) — камни, кусты, деревья, свои объекты
- Базовые формы **Flat, Round, Cone, Spike**; Deformation и Structure для деталей (детализация дальнего плана, не hero-ассеты); высота, размер, вариация; количества вроде 75,000 считаются быстро.
- Ограничение фильтрами: **Altitude** (со смягчением) и **Slope** (например, не на самых ровных или крутых участках). Второй tfDistribute с Cone и низкой деформацией = деревья.
- С материалом террейна: **Add Rock Layer / Add Tree Layer** автоматически создают редактируемые слои материала + маски.
- **Свои объекты из битмапов** (например, логотип, 500 копий); размещение **Surface** или **Intersect** (объекты выпирают, как скалы).
- Генерирует **object masks и object IDs** для рендера и симуляций частиц.
