# Обзор функций: mtPointProject и новые режимы mtSubdivider (MeshTools 2024.2)

- Источник: MeshTools Sneak Peek — Project Objects and Splines onto Scene Geo, Release Update Coming Soon — https://www.youtube.com/watch?v=LPsWJoXKhQk (2024-05-02)
- Хост / поколение: C4D; MeshTools (процедурное моделирование); в одном демо из результата эмитятся частицы NeXus
- Статус: превью **Fused 2024.2** (9 мая 2024)

## mtPointProject (новый)
- Проецирует точки любого дочернего объекта или **spline** (например, текстового сплайна) на объект **Surface** (камень).
- Среди режимов — **+Z** и **Parallel +Y / −Y** (проекция вверх или вниз на поверхность).
- Слайдер **Blend**: 0 = исходное положение, 100 = полностью спроецировано (например, 97, чтобы остался намёк на исходную форму).
- Всё живое: поверхность может быть с ключами или под деформерами, источник — анимирован (анимированный крест на деформируемой поверхности), проекция остаётся стабильной.
- Эмиттер может эмитить прямо из объекта mtPointProject → частицы NeXus рождаются из букв на поверхности камня.

## mtSubdivider — четыре новых режима помимо Bilinear
- **Bilinear Offset**: смещает поделённые полигоны для тайловых паттернов.
- **Shards**: делит каждый родительский полигон на настраиваемые осколки со сплайном контроля детализации.
- **Whirl**: сцепленные внешние полигоны; Strength задаёт размер внутреннего полигона.
- **Catmull-Clark**: режим сглаживания, например второй subdivider поверх анимированного mtInset для скруглённых смещений.
- Управляется через Fields/шейдеры (линейный или круговой градиент = подразбиение расходится от центра); складывается с mtInset и остальными MeshTools; все параметры можно анимировать ключами.

## Как сейчас (новые инструменты)
Вошло в Fused 2024.2; см. «Projected spline emission on an animated surface» (2024-07-02). Эмиссия из спроецированной геометрии точно так же работает с nxEmitter в NeXus 2026.
