# Цветок кувшинки / лотоса (Taiao Flower: слои лепестков, Fold, Furling, кольца тычинок)

- Источник: Bite-Sized — Taiao Water Lily — https://www.youtube.com/watch?v=E1P088VK0lk (2025-10-23)
- Хост / поколение: C4D; объект **Taiao Flower** (INSYDIUM ▸ Taiao ▸ Flower); без частиц
- Задача: смоделировать многоярусный, слегка неровный цветок кувшинки, который можно ещё и анимировать раскрытие.

## Шаги
1. Добавьте **Taiao Flower**. Удалите слой **Sepal**, оставьте **Pistil**, **Stamen** пока скройте.
2. Petal ▸ Geometry: **Length segments ~25**, **Width segments 6**. Сведите кончик в точку, расширьте основание.
3. Petal ▸ Modifiers: сильно поднимите **Fold**; на его **Bias spline** опустите конец, чтобы основание оставалось плоским, а сгиб нарастал к кончику (добавьте узел для органичной кривой).
4. **Furling**: угол вверх — лепесток в форме лодочки; подстройте его bias, чтобы немного уплостить.
5. Добавьте модификатор **Turbulence**: **Vary Seed** (каждый лепесток разный), больше силы, bias ~1%, крупнее масштаб (меньше значение scale) — только едва заметно.
6. Geometry ▸ **Edge Noise**: немного, масштаб поменьше, чтобы сломать контур.
7. Main ▸ **Layer count 5**, поднимите **Layer step** (вертикальное смещение), **Layer rotation ~20–25°**, чтобы каждый ряд вставал между лепестками нижнего; понизьте верхнее значение **Layer scale**, чтобы внутренние лепестки были меньше.
8. Orientation: наклоните внутренние лепестки вверх; **Angle twirl/bias** опускает нижние ряды — анимируйте ключами, чтобы цветок раскрывался. Заново подстройте Layer step и **Radius**, чтобы закрыть зазор в центре.
9. Pistil: **Subdivisions 2** для гладкой головки.
10. Внешние тычинки: Distribution **Spiral → World** (кольцо), радиус кольца больше, count выше. Geometry: уберите две точки головки, **Height segments 20**, **Width segments 8**, сильная вариация размера.
11. Модификаторы тычинок: два слоя **Furling** — первый закручивает внутрь (низкий bias), второй наружу → S-изгиб; плюс Turbulence (vary seed, маленький размер).
12. Добавьте второй слой Stamen для внутреннего кольца: та же геометрия, распределение World, **Ring count 1**, радиус меньше, Furling внутрь с небольшим зазором на кончике, чуть короче, больше вариации + турбулентность.
13. Назначьте материалы на каждый слой.

## Подводные камни
- В субтитрах написано "failing/filling layer" — модификатор для завитков тычинок — это Furling.
