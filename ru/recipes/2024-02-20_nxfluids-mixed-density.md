# Слои жидкостей разной плотности (density в nxFluids tag для SPH / радиус для PBD)

- Источник: Top Tip Tuesday — nxFluids Mixed Density — https://www.youtube.com/watch?v=4o0RR_tttIE (2024-02-20)
- Хост / поколение: C4D; NeXus GPU (nxFluids SPH/PBD, **nxFluids tag**, nxGravity)
- Задача: расслоение как у масла на воде — три эмиттера льют в колбу, и жидкости оседают слоями.

## Исходная сцена
Колба из Lathe с xpCollider tag; nxGravity по умолчанию; **nxFluids SPH, 7 substeps**. Три эмиттера (оранжевый, синий, зелёный), эмиссия Regular, speed 300, radius 5, со смещённым временем старта.

## Шаги (SPH)
1. Выделите все эмиттеры ▸ Tags ▸ INSYDIUM ▸ **nxFluids tag** (свойства жидкости для каждого эмиттера). [▶ 1:57](https://youtu.be/4o0RR_tttIE?t=117)
2. Вкладка SPH, **Density**: оранжевый 200, синий 800, зелёный 1600 → зелёный тонет, оранжевый всплывает. [▶ 2:18](https://youtu.be/4o0RR_tttIE?t=138)
3. Поставьте зелёному 100 — он постепенно пробивается вверх; 10 — быстро всплывает наверх. [▶ 1:40](https://youtu.be/4o0RR_tttIE?t=100)

## Шаги (PBD)
4. Переключите nxFluids на **PBD** — плотность не используется; вместо неё задайте **радиус частиц**: зелёный 3, синий 5, оранжевый 7. Крупные частицы всплывают над мелкими. [▶ 5:01](https://youtu.be/4o0RR_tttIE?t=301)

## Подводные камни
- Для стабильности SPH нужен одинаковый радиус у всех частиц; PBD нормально переносит разные радиусы.

## Как сейчас (новые инструменты)
FLIP/APIC **Mixer** для каждого эмиттера/группы (плотность, вязкость, поверхностное натяжение…) в 2026.1 beta.
