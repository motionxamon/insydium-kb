# Как сделать, чтобы террейн «выстреливал» во вьюпорте (детализация tfTerrain + дневной риг из двух источников)

- Источник: Top Tip Tuesday — TerraformFX Light Rig — https://www.youtube.com/watch?v=-lLpDIbbDaA (2023-04-18)
- Хост / поколение: C4D; TerraformFX (без частиц); источники света C4D, базовое отображение во вьюпорте
- Задача: детализированный ландшафт в свете «золотого часа» даже в обычном вьюпорте.

## Исходная сцена
INSYDIUM ▸ TerraformFX ▸ **tfTerrain** (noise по умолчанию + два фильтра эрозии → эрозии удалите). Вкладка Object: цветовой градиент выкл., чтобы оценивать оттенки серого.

## Шаги
1. Segments **500 → 1000** — больше полигонов.
2. **tfNoise** ▸ Properties: **Octaves 14** = дешёвая дополнительная мелкая детализация; тип noise **Stupl**; вкладка Operator **Gain 90**.
3. tfTerrain ▸ Boundaries ▸ **Even Border** → ровные края на уровне моря, холм посередине.
4. Солнце: C4D Light, оранжевый (золотой час), тип **Infinite** (светит вдоль +Z), опускайте поворотом, пока он не будет едва скользить по горизонту; **Soft Shadows**, тень **Density 88%**, intensity **130%**.
5. Заполняющий свет неба: второй источник, синий, **Ambient Illumination**, низкая интенсивность → дымчатые тени и ощущение масштаба.
6. Фильтр вьюпорта: скройте источники света.
7. Снова включите цветовое отображение террейна (градиент по высоте): пресет **Alpine → Atacama Desert**.
8. Детализация для крупных планов: segments **3000**.
