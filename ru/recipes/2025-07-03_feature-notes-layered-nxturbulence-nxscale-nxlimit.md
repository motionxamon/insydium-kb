# Обзор функций: слоёный nxTurbulence, nxScale и новый nxLimit (превью Fused 2025, часть 1)

- Источник: Fused 2025 Tech Preview — Modifier Improvements Part 1 — https://www.youtube.com/watch?v=Ec1tTKMlHBM (2025-07-03)
- Хост / поколение: C4D; GPU-модификаторы NeXus (nx…) на xpEmitter (G2); финальный вид в Redshift
- Статус: превью инструментов, которые вышли в **Fused 2025.4** (декабрь 2025) как «слоёные модификаторы»

## Что изменилось
- **Стек слоёв в одном объекте**: каждый модификатор хранит список слоёв; добавляй из выпадающего списка слоёв или дублируй Ctrl-перетаскиванием. Слои смешиваются сверху вниз, как в Photoshop — **Normal на 100% перекрывает всё, что ниже**, ползунок Strength подмешивает, **Multiply** модулирует слой под собой. Один объект заменяет стек из 5–10 отдельных турбулентностей.
- nxTurbulence с одним слоем (по умолчанию Voronoise) ведёт себя как старый nxTurbulence.

## nxTurbulence
- Рецепт из трёх слоёв: внизу **Curl** (крупный завихрённый поток: Frequency ~12, Scale ~380), в середине **Voronoise** (масштаб меньше, частота ниже; подними Strength, чтобы появились ленты), сверху **FBM** (мелкие прожилки: Scale ~83, очень низкая частота). Пока настраиваешь нижний слой, ставь верхним Strength 0, потом вводи их по одному.
- Детализацию лучше всего видно в отображении Dot; в Redshift уже <0.5 M частиц читаются как богатая детализация.
- Новый **Mode: Direction** (вместо дефолтного Acceleration): частицы остаются на месте, но их направление анимирует noise; работает с любым типом noise (Cubic = длинные ленивые повороты, Simplex = быстрые плавные, Voronoise = дёрганые). В пару — у эмиттера Display ▸ Color **Gradient by Parameter → Direction** для бликов.

## nxScale (radius / scale / mass)
- Классические слои остались (Set Value, Change over Time, Set by Falloff), плюс два новых:
- Слой **Range**: Timing **On Birth** (Radius End + вариация, перекрывает radius эмиттера) или **Particle Age** (Radius Start → End за время Start/End, например 0–60 F, форма задаётся кривой Ease; дополнительная точка = вырасти, потом уменьшиться). Режимы ограничения: **Clamp** (только внутри окна), **Repeat** (пульсация), **Continue** (продолжает расти с той же скоростью). Вариация и на значениях, *и* на времени.
- Слой **Noise**: 3D GPU-нойзы INSYDIUM (тот же набор и настройки, что в nxTurbulence, плюс low/high clip, brightness, contrast) переводят чёрное → Radius Start, белое → Radius End. Заменяет C4D Fields для размера от noise и остаётся на GPU.
- Пример смешивания: слой Range пульсирует размером; слой Noise над ним в **Multiply** с **Radius End 1** (чтобы он масштабировал только в пределах 0–1), Radius Start ~0.4–0.6, чтобы noise был мягче.

## nxLimit (новый)
- Слои: velocity, position, scale, rotation, speed, radius.
- Слой **Position**, мировые координаты: ограничение по Y **Fixed** на 0 сплющивает облако, которое расталкивает nxPush, в плоскость — заменяет старые трюки с velocity/speed в nxQuestion. По X и Z **Range** −200…200 cm (+ вариация, чтобы смягчить края) запирает его в коробку; режим координат **Particle** даёт более мягкую границу.
- Слой **Radius**: ограничение максимума (например, 15, 10, 20 cm) и/или минимума (5) поверх nxScale от noise — меняет ячеистый узор пятен в push-симуляции (birth rate 20,000/s, отображение Square).

## Как сейчас (новые инструменты)
Все три вышли в Fused 2025.4; в NeXus 2026.1 у каждого слоя ещё и свой список Falloff и 16 режимов nxFalloff; см. «nxTurbulence Direction mode clones» (2026-01-20).
