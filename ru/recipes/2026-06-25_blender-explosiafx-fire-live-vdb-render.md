# Огонь с горением топлива и дым с живым рендером в Cycles (источники nxExplosiaFX, силы, Adaptive Bounds, VDB Output Live)

- Источник: NeXus for Blender Official Training — Fire Sim — https://www.youtube.com/watch?v=RH6ukNvt-No (2026-06-25)
- Хост / поколение: Blender (NeXus for Blender, G3); GPU-воксельный домен **nxExplosiaFX**; Cycles GPU (Eevee тоже работает)
- Задача: арт-директорски управляемое пламя + дым от Сюзанны, рендер без кэширования через автоматически создаваемый Blender volume и пресетный материал.

## Исходная сцена
Домен nxExplosiaFX (по умолчанию: **voxel size 0.04 m, домен 4 m**), пол удалён; маленькая Сюзанна внизу домена. Источниками могут быть меши, кривые или частицы; несколько источников могут делить одну сетку.

## Шаги
1. **nxExplosiaFX ▸ Object ▸ Sources**: добавьте Сюзанну. Каналы по умолчанию излучают temperature 1000, fuel 0.2, pressure, smoke 0 — дым всё равно появляется, потому что горящее топливо его выделяет. [▶ 2:02](https://youtu.be/RH6ukNvt-No?t=122)
2. Два способа управлять видом: (a) излучать только **Temperature + Smoke** (fuel выключен) — быстро, без горения; (b) излучать **Fuel** и формировать результат в **Simulation ▸ Burning** (дым и температура возникают при горении; слишком много дыма душит пламя). Можно совмещать (fuel + немного дополнительного smoke = более густой дым). Pressure выставлен в 1. [▶ 3:06](https://youtu.be/RH6ukNvt-No?t=186)
3. Разбейте эмиссию: у источника **Weight By ▸ GPU Noise** — белые участки излучают топливо, чёрные нет; анимированный noise даёт языки пламени; меньший Strength добавляет серые тона для мягкой вариации. [▶ 6:08](https://youtu.be/RH6ukNvt-No?t=368)
4. **Dynamics ▸ Forces** (по умолчанию Simplex turbulence + Vorticity; сначала их убрали, чтобы увидеть «сырой» поток, затем собрали заново): [▶ 7:01](https://youtu.be/RH6ukNvt-No?t=421)
   - **Turbulence** для крупных завихрений: проверьте на Strength 50, чтобы увидеть эффект, затем **Length Scale 10**, **Strength 25**.
   - **Vorticity** для мелкой детализации (усиливает существующие завихрения, не добавляет движения): слишком много = дым как вата; ~8 на стандартном разрешении.
5. Разрешение: **Voxel size 0.02** (≈10× VRAM, гораздо больше деталей). Более мелкой сетке нужно меньше vorticity → снизьте до **2**. [▶ 10:27](https://youtu.be/RH6ukNvt-No?t=627)
6. Пламя горячее, но не выше: поднимите температуру в Burning (8000 → 10000), затем **Temperature Dissipation ~1.2** (2 = очень низкое пламя). **Smoke Dissipation**: 0.2 — дым висит; **1.5** оставляет вокруг пламени ровно столько дыма, сколько нужно для рассеивания/поглощения на рендере. [▶ 12:48](https://youtu.be/RH6ukNvt-No?t=768)
7. **Display ▸ Viewport HUD ▸ Draw Adaptive Bounds** — видно, где идёт расчёт. Пороги каналов **Solver ▸ Adaptive Bounds**: слишком высокие (например, smoke 1) = дым обрезается и выскакивает; по умолчанию 0.01, **0.001** для продакшн-затуханий (границы больше, считается медленнее). [▶ 13:28](https://youtu.be/RH6ukNvt-No?t=808)
8. Кадрирование: увеличьте домен, чтобы его верх был за пределами камеры, а бока не обрезали дым (X/Y **4.5**, Z выше). Следите за **Estimated Persistent / Peak VRAM** в Simulation — здесь пик вырос примерно с 1.16 до 2.2 GB; держите пик заметно ниже объёма VRAM карты. [▶ 17:47](https://youtu.be/RH6ukNvt-No?t=1067)
9. **Вкладка Render ▸ VDB Output: Live** → временная VDB-последовательность, автоматический объект Blender Volume, подключённый ко всем каналам, пресетный материал огня/дыма; сим остаётся живым (cache не нужен). Альтернативы: nxCache или экспорт VDB + импорт volume в Blender. [▶ 22:11](https://youtu.be/RH6ukNvt-No?t=1331)
10. Пресетный материал: Flame — интенсивность горячей сажи, сила прямой эмиссии, **Temperature Minimum** (по умолчанию 1100; 3000 = пламенем рендерится только короткое горячее ядро). Smoke — Extinction (например, 200 = плотный), Albedo, Anisotropy. [▶ 23:56](https://youtu.be/RH6ukNvt-No?t=1436)
11. Cycles GPU: чёрный world, area light (Normalize выключен, Track To на Сюзанну), Max Samples 1000 + GPU denoise; **Advanced ▸ Seed > 0** (фиксированный паттерн шума лучше для денойза); **Light Paths ▸ Volume bounces 1**. **Render ▸ Lock Interface** — для любого рендера NeXus. [▶ 26:16](https://youtu.be/RH6ukNvt-No?t=1576)

## Подводные камни
- Настройки Burning ничего не делают, если топливо не излучается.
- Небольшие изменения домена/вокселя быстро умножают расход VRAM.

## Как сейчас (новые инструменты)
Тот же объект в NeXus 2026.1 beta; добавьте **nxWarp** (Deform/Guide/Flow) на дым для управляемых форм и nxFalloff на каждый слой сил. Пользователи C4D получают тот же солвер плюс связку с Pyro (C4D 2025.3+).
