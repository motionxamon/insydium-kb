# Обзор функций: Taiao 2024.2 — разброс через growth points, слои жилок toLeaf, сплайн Angle Bias у furling

- Источник: Taiao Sneak Peek — Final Sneak Peek, Release Update Coming Soon 2024.2 — https://www.youtube.com/watch?v=TZsJmCkC9Nw (2024-05-06)
- Хост / поколение: C4D; Taiao (toPlant, toLeaf, toFlow) — процедурные растения, без частиц
- Статус: превью **Fused 2024.2** (9 мая 2024)

## toPlant ▸ слой Growth Point (разброс по объектам сцены)
- Любой объект (лист, гриб, примитивы, полигональные объекты) раскладывается по поверхности (бревну); режим **Multi-Instance** для эффективности; количество точек, например, 1,000 → 5,000.
- Распределение: перетащите тег **Vertex Map** в поле selection; добавьте **shader** (noise с Low Clip) для дополнительной случайности — перебирайте seed, регулируйте **Tolerance**.
- Масштаб и поворот объектов с вариацией.
- Разделение **Spacing**: **Kill** удаляет слишком близкие инстансы; **Push** вместо этого расталкивает их.
- Можно складывать несколько слоёв Growth Point (листья + грибы + цветы).

## toLeaf ▸ новая система слоёв жилок
- Слой **Mid Vein**: радиус, кривая профиля, **petiole offset** (продолжение черешка), при желании параллельные жилки (vein count). Жилки всегда лежат на поверхности листа, как бы его ни деформировали.
- **Стек модификаторов на каждую жилку**: например, Turbulence и Bend только на одну жилку; отдельный furling-модификатор только для продолжения черешка.
- Слой **Lateral Vein**, четыре структуры: Pinnate, Arcuate (загнутые кончики), **Palmate** (веером), **Dichotomous** (ветвление, Split Count). Количество жилок, сплайн профиля, угол, вариация смещения/угла, сплайн распределения; свои модификаторы. Lateral-слои можно складывать (жилки третьего порядка: короче, под углом, со смещением).
- **Remove Intersections** — одна кнопка, работает на всех уровнях жилок.
- Новая **библиотека пресетов листьев** (реальные листья) в браузере пресетов Taiao.

## Модификатор furling (toFlow, toLeaf, toPlant)
- Angle и Bias остались, плюс **сплайн Angle Bias** — один furling-модификатор теперь даёт обратное скручивание и S-изгибы (больше не нужно складывать несколько).
- Только в toFlow: **сплайн Layer Bias** для отдельных слоёв лепестков → лёгкая анимация раскрытия многослойных цветков.
