# Послойное растворение объёма (nxQuestion Neighbor Count → Group → nxWind/nxColor)

- Источник: Top Tip Tuesday — Surface Particle Dissolve — https://www.youtube.com/watch?v=35Yxc9a2QOU (2025-02-18)
- Хост / поколение: C4D; NeXus G2 nxQuestion (поиск соседей), nxWind, nxColor на xpEmitter
- Задача: заполненная частицами модель, которая слой за слоем разрушается с внешней поверхности.

## Исходная сцена
xpEmitter ▸ Object (собачка из шариков) ▸ **Volume**; Emission Shot **500,000**, полный lifespan, Speed 0, Radius 1. Модель скройте.

## Шаги
1. Groups: дважды Ctrl-клик по **Add Group**, **First Group Only**.
2. **nxWind** и **nxColor** (цвет по направлению) ▸ Groups Affected = **группа 2** — пока ничего не происходит.
3. **nxQuestion**: Particle **Neighbors** в пределах **10 cm** **меньше 70** → проверьте через Set Color жёлтый; подсвечивается только внешняя оболочка (у частиц на поверхности меньше соседей).
4. Поднимите порог (80, 100) для более толстой оболочки; использовано 100.
5. Замените action на **Set Group = группа 2**; включите wind + color.
6. Вопрос пересчитывается каждый кадр, поэтому каждый новый открывшийся слой становится «поверхностью» и сдувается, пока объект не исчезнет.
7. Управление скоростью: порог ниже (70) = оболочка тоньше = разрушение медленнее.

## Подводные камни
Порог соседей зависит от радиуса/плотности — прикиньте, проверьте через action с цветом, потом переключите на action с группой.
