# Наполняем сцену из одного кэша частиц (локальные координаты xpCache, Copy Tag Data, сдвиг на каждом теге)

- Источник: Top Tip Tuesday — Duplicate Particle Caches — https://www.youtube.com/watch?v=dA4cn2wx47A (2024-12-03)
- Хост / поколение: C4D; эмиттер + симуляция nxTurbulence, **xpCache** (CPU-система кэширования, работает и для NeXus)
- Задача: много разных дымоподобных шлейфов для фонов из одного кэша.

## Шаги
1. **xpCache**: внешние файлы, сжатие при сборке → Build (2000 F ≈ 1.5 мин в этом примере). [▶ 0:40](https://youtu.be/dA4cn2wx47A?t=40)
2. Перемещение закэшированного эмиттера ничего не меняет → xpCache ▸ **Playback ▸ Local Coordinates** → кэш следует за эмиттером; в режиме Object его можно **масштабировать** (даже неравномерно) и вращать. [▶ 1:40](https://youtu.be/dA4cn2wx47A?t=100)
3. Дубликаты: на теге кэша эмиттера включите **Copy Tag Data** перед Ctrl-drag → тег копии остаётся привязанным (красный) к тому же кэшу (иначе зелёный = данных нет). [▶ 2:50](https://youtu.be/dA4cn2wx47A?t=170)
4. Вариации для каждой копии на её **теге кэша**: **Override cache object settings** → Local Coordinates вкл. + **Offset** (например, 100, 200, 250 кадров), чтобы шлейфы были на разных стадиях. [▶ 4:33](https://youtu.be/dA4cn2wx47A?t=273)
5. Двигайте / вращайте / масштабируйте каждую копию → целый фон из одной симуляции. [▶ 5:36](https://youtu.be/dA4cn2wx47A?t=336)
