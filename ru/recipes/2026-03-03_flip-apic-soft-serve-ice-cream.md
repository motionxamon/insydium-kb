# Завиток мягкого мороженого (nxFluids APIC, вязкость, гравитация с маппингом по возрасту)

- Источник: Top Tip Tuesday — FLIP Ice Cream — https://www.youtube.com/watch?v=ooB36pUD8Ys (2026-03-03)
- Хост / поколение: C4D, Fused 2025.4+ (nxFluids FLIP/APIC, nxMesher)
- Задача: рифлёный закручивающийся вязкий завиток, который держит форму.

## Эмиссия (форма из сплайнов)
- Эмиссия из **Star spline**, привязанного к Circle через Align to Spline; позиция звезды анимирована по кругу, круг опускается и сжимается, в конце звезда сжимается → кончик.
- Rate 1000/кадр (2000 для финала), скорость 0.

## Симуляция
1. **nxFluids APIC** (ограниченный домен 200³), **Voxel Size 4** (по умолчанию слишком грубо), **Viscosity ~300**. **nxGravity** по умолчанию.
2. Ступенчатость от тонкого источника без начальной скорости → Project Settings (Ctrl+D) ▸ X-Particles **Subframe Steps 5** (8 для финала).
3. Чтобы завиток не проседал/не таял: nxGravity **Mapping** → **Age** → Gravity Strength, диапазон **40–50 F**, кривая от полной → 0 (гравитация отключается, как только виток лёг; двигают его только нажимы сверху).
4. Финальное качество: Solver Accuracy → **Viscosity accuracy full**, у флюида **Min/Max Substeps 3/5** (отдельно от сабфреймов сцены). Кэш ≈ 8 мин.

## Мешинг (nxMesher)
- Radius ~1.8, **Polygon Size 1**. Для плотных складок используйте **Spheres** (Zhu-Bridson сглаживает острые складки) + **Smoothing layer Mean Curvature** (или Laplacian) на полную, **7 iterations**.

## Подводный камень
Эмиссия со сплайна = полая оболочка; нормально, если камера не видит внутрь, иначе заполняйте сплошной объём гораздо большим числом частиц.
