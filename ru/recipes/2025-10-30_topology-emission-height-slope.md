# Эмиссия по высоте и уклону — снежные шапки, осевшая пыль (xpEmitter Object ▸ Topology)

- Источник: Bite-Sized — Topology Emission — https://www.youtube.com/watch?v=uA6Eo2v_9hs (2025-10-30)
- Хост / поколение: C4D; обычный **xpEmitter** (без модификаторов), в качестве источников — террейн TerraformFX и C4D Torus
- Задача: разместить частицы только там, где поверхность достаточно высокая и/или достаточно пологая (снег на вершинах, пыль сверху на объектах).

## Исходная сцена
**xpEmitter** ▸ Object: эмиссия с острова TerraformFX, **Polygon Area**. Emission: **Shot**, **Simulate** (частицы уже на кадре 0), скорость 0, ~100,000 частиц. В источнике задайте Basic ▸ Display Color свой чёрный, чтобы частицы хорошо читались.

## Шаги
1. Emitter ▸ Object ▸ подвкладка **Topology** ▸ включите **Height**: диапазон по умолчанию 0–200 см. Опускайте Max, пока верхние частицы не исчезнут, — так найдёте реальную высоту террейна (~81 см в демо).
2. Снежные шапки: Max чуть выше пика (~90), затем поднимите **Min Height** до линии снега.
3. Мягкая граница снега: **сплайн высоты** — это объём эмиссии по диапазону; опустите нижний узел, чтобы частицы редели к Min, а не обрывались резко.
4. Выключите Height, включите **Slope**: по умолчанию 0–90°. Уменьшите **Max Slope**, чтобы убрать частицы с самых крутых граней (голые скалы).
5. Height + Slope вместе: только высокие и не слишком крутые участки, с поредением ниже.
6. Геометрия сцены (пыль): эмиссия с Torus, Topology ▸ только Slope, Max 90°, затем сплайном уклона разредите частицы на более крутых участках, откуда пыль бы ссыпалась.

## Подводные камни
- Видимые ступеньки в градиенте = мало полигонов (уклон считается по граням). Поднимите у Torus **Pipe Segments** (или подразделите) для плавного перехода.

## Как сейчас (новые инструменты)
На GPU/NeXus 2026 ту же маску можно собрать через режимы nxFalloff, например **Curvature**, **AO** или **Attribute**, на слоях эмиссии/модификаторов; вкладка Topology у xpEmitter остаётся самым быстрым способом на CPU.
