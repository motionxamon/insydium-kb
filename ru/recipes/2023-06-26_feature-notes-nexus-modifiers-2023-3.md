# Обзор функций: новые модификаторы NeXus — nxUpres, nxInfectio, nxWave, nxAvoid, nxFlock, режимы nxBlend, nxFoam на кэшах, nxWind Von Karman (Fused 2023.3)

- Источник: INSYDIUM Fused Release Update — July 2023 - NeXus Modifiers Sneak Peek — https://www.youtube.com/watch?v=c-Xh7p3xq-g (2023-06-26)
- Хост / поколение: C4D; G2 NeXus внутри X-Particles (GPU) — Fused 2023.3
- Задача: обзор GPU-модификаторов, добавленных/обновлённых в июле 2023.

## Новое
- **nxUpres** — Source = закэшированный эмиттер с малым числом частиц, Destination = эмиттер с большим числом; живой результат высокой плотности, управляемый скоростью источника; интерполирует Velocity, Radius, Color и другое, так что исходные модификаторы не нужны.
- **nxInfectio** — «вирусное» распространение на соседние частицы, теперь на GPU (органический рост, управление модификаторами во fluid-симах).
- **nxWave** — живое поле скоростей, создающее анимированные волны во fluid-симах; режимы отображения для настройки; **6 собственных типов noise**.
- **nxAvoid** — GPU-избегание объектов частицами; в список идут любые объекты/генераторы (например, куски xpShatter между стенами); при обнаружении — **смена направления**, **заморозка** или **смерть**.
- **nxFlock** — GPU-флокинг; слои поведений (например, chaos, cohesion), объекты **pursuit**, за которыми гоняться, и частицы-**враги**, от которых убегать.

## Обновлено
- **nxFoam** генерирует живую пену на **закэшированных** fluid-симах (достаточно добавить foam-эмиттер).
- **nxWind** — новый режим **Von Karman**, физически правдоподобные порывы.
- **nxBlend** — режимы смешивания (**Multiply, Screen, Overlay**…) и новая вкладка **Weighting** с весами по слоям на каждый эмиттер.

## Что заменяет
CPU-спавн из кэшей в духе xpUpres, xpInfectio, xpAvoid, xpFlock для GPU-эмиттеров. Сейчас: nxUpres и nxFlock актуальны; спавн → **nxSpawn** (2026.1 beta); nxFoam переписан со слоями foam/bubbles/spray (2025.4); связка nxWave → **nxOcean** с FLIP coupling (2026.1 beta).
