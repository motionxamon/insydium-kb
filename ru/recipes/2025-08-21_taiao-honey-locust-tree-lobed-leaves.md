# Молодая гледичия (Taiao Plant: 3 уровня веток + Join-меширование, Taiao Leaf: лопастные перистые листья)

- Источник: INSYDIUM Official Training — Taiao Honey Locust Tree — https://www.youtube.com/watch?v=uGQ2s-J1tog (2025-08-21)
- Хост / поколение: C4D; Taiao Plant (toPlant) + Taiao Leaf (toLeaf); стандартные viewport-материалы (любой рендер)
- Задача: небольшое дерево с ровно срезанной верхушкой, управляемым объёмом веток и сложными листьями.

## Совет перед моделингом
Найдите зимний (без листвы) референс того же вида и зарисуйте поверх структуру веток — на летних фото её не видно.

## Ствол
1. Taiao Plant ▸ trunk высотой по умолчанию (дерево ≈ 12–15 ft); Global ▸ spline segments **5**; ring segments **24** (ровные квады); radius **~5**.
2. Модификатор **Turbulence**, bias слегка поднят (~0.1%) от основания; noise по умолчанию подходит (прокрутите Seed для вариаций).

## Ветки
3. Добавьте **Branch**: **Branch on End off** (плоская верхушка). Count **15**, вариация длины, угол вверх + вариация, модификатор **Gravity**, чтобы тянуть их обратно вниз.
4. **Distribution curve** = силуэт кроны сбоку (x = вдоль родителя, y = насколько далеко наружу) — добавляйте узлы, чтобы нарисовать объём.
5. **Branch length curve** вдоль родителя: короче у основания и наверху, длиннее в середине. Turbulence (bias от основания) + Gravity; если сильно провисают, снова поднимите угол и понизьте **angle bias** у основания.
6. Добавьте второй слой **Branch** (подветки): count **5**, Branch on End off, угол вверх, вариация длины, слабее Turbulence + Gravity, распределение ближе к основанию.
7. Третий уровень под листья: скопируйте слой подветок Ctrl-перетаскиванием под самого себя, сильно укоротите длину, смягчите турбулентность.
8. Материал коры на стволе; включите кнопку **propagate**, чтобы его получили все уровни веток; **V tiles 6**.
9. Global ▸ Meshing type **Intersect → Join**, **Maximum join level 1** (свариваются только ствол и первые ветки — остальное скрыто листьями); subdivision 1.

## Лист
10. Taiao Leaf: **10 length** сегментов, настройте профиль, **Edge Noise**, 1 subdivision; **Midvein** с суженным кончиком и небольшим смещением **petiole**.
11. Модификаторы: **Fold** (настроенная кривая, наружу и вокруг), **Furl**, лёгкий **Turbulence** (bias вверх).
12. Тип листа **Lobed**, без листа на конце (как у реального вида), **count 18**; профиль rachis тоньше к концу, радиус чуть больше, length segments **40** (держите низко ради скорости).
13. Листочки: вариация размера + кривая size bias, вариация распределения, угол вверх с bias (задние меньше вперёд), **Twist** вверх, вариация на всём. Модификаторы rachis: Furl (провисание) + Turbulence.

## Сборка
14. Последний слой веток ▸ Add **Leaf**: Geometry **Basic → Custom**, привяжите лист; size **0.5** + вариация, count **8**, угол вверх + вариация.
15. Всё остаётся процедурным — например, укоротите ветки/подветки, поднимите распределение, count 10, чтобы совпасть с референсом.
