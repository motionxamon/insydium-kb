# Выброс частиц с плавной органичной остановкой (nxSpeed Range + curl-турбулентность)

- Источник: Top Tip Tuesday — Speed Range — https://www.youtube.com/watch?v=HvX6qaVei1o (2026-03-31)
- Хост / поколение: NeXus (nxTurbulence Curl, nxSpeed Range) + xpTrail — C4D
- Задача: частицы вылетают из круга, турбулентно блуждают и естественно замедляются до полной остановки, рисуя трейлы.

## Шаги
1. Эмиттер Circle, стреляющий наружу; xpTrail на эмиттере.
2. **nxTurbulence** → слой **Curl**, Scale побольше, Frequency пониже (без дрожания). **Add выкл.**; **Blend ~64%** = какая доля движения идёт от curl, а какая от собственной скорости частицы (100% = только шум, 0 = только скорость частицы).
3. **nxSpeed** *ниже* турбулентности → слой **Range**: Speed Start 0 / End 300 на 0–60 кадрах. **Переверните ease-кривую**, чтобы старт был на полной скорости (300), а конец на 0 → вылет и остановка с плавным замедлением.
4. Вариация на End Time (~36 F) и на максимальной скорости → частицы останавливаются в разные моменты = органично.
5. Трейлы длиннее: поднимите End Time (например, 85 F).

## Примечание
Слои Range (nxSpeed, nxScale, nxSpin, nxColor…) — рекомендуемые «универсальные» слои начиная с Fused 2025.4: начальное/конечное значение, время начала/конца, ease-кривая, вариации на всём.
