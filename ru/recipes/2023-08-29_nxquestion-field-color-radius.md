# Частицы растут и меняют цвет внутри поля, а снаружи возвращаются обратно (nxQuestion Field question, Set Color / Set Radius, Else)

- Источник: Top Tip Tuesday — nxQuestion Fields — https://www.youtube.com/watch?v=c1-Os0yoIgg (2023-08-29)
- Хост / поколение: C4D; G2 NeXus nxQuestion (переработка в Fused 2023.3) на xpEmitter; C4D Spherical field
- Задача: частицы на поверхности головы волка раздуваются и синеют, пока по ним проходит анимированное поле, а затем сжимаются обратно.

## Исходная сцена
Частицы рождаются на поверхности головы, радиус **2 cm**.

## Шаги
1. **nxQuestion** только с **Action** (без вопроса) = действует на все частицы сразу. По умолчанию **Set Color** → синий.
2. Уменьшите **Weight** действия, чтобы изменение шло постепенно за несколько кадров, а не мгновенно.
3. Скопируйте действие через Ctrl-drag, переключите на **Set Radius**, **20 cm**; оно наследует низкий weight (~4%) → постепенный рост; 100% = мгновенно.
4. Привяжите анимированное поле во вкладке **Fields** у nxQuestion.
5. Добавьте **Question** и сделайте оба действия его дочерними. По умолчанию там Age > 30 frames (действия срабатывают с 30-го кадра) → смените тип данных на **Field**.
6. Значение поля от 0 до 1: 1 внутри внутренней сферы, 0 снаружи внешней, между ними falloff. Проверка по умолчанию **> 0.5** срабатывает только от середины falloff внутрь; **> 0** — как только частица касается внешней сферы.
7. Возврат: добавьте второй Question **под** первым (вычисляются по порядку), переключите его с **If** на **Else**; скопируйте под него оба действия: Set Color обратно в исходный фиолетовый, Set Radius обратно на **2**.
8. Поднимите weight у Set Radius в Else, чтобы сжатие шло быстрее (слишком высокий = резко).

## Как сейчас (новые инструменты)
Та же логика в NeXus 2026.1 / Blender, только с **nxFalloff** (16 режимов) вместо C4D fields; для чистого управления через falloff без логики привяжите Radius/Color к falloff во вкладке Mapping модификаторов или используйте **nxScale**/**nxColor** со списками Falloff на каждом слое. Quill (Blender) может набросать такие деревья вопросов.
