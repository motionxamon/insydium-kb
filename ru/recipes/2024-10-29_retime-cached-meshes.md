# Рампа замедления на мешированной жидкости (ретайм кэша частиц, затем кэш мешера из ретаймленных частиц)

- Источник: Top Tip Tuesday — Retime Cached Meshes — https://www.youtube.com/watch?v=SiDN-95Yk88 (2024-10-29)
- Хост / поколение: C4D; ретайм в **xpCache** + CPU xpOpenVDBMesher
- Задача: плавное слоу-мо на одном всплеске — и для частиц, и для меша.

## Шаги
1. xpCache ▸ Playback ▸ Retiming **Time (seconds)**: ключ 0 s на кадре 0 и 500/30 = **16.6 s** на последнем кадре; кривая **Linear**. [▶ 0:52](https://youtu.be/SiDN-95Yk88?t=52)
2. Добавь два ключа вокруг всплеска, выдели оба, сдвинь вправо → пологий участок = слоу-мо. [▶ 1:56](https://youtu.be/SiDN-95Yk88?t=116)
3. Частицы плавно интерполируются **только при фиксированном числе частиц** (все рождены на кадре 0); динамически порождённую пену заполнить промежуточными позициями нельзя. [▶ 2:53](https://youtu.be/SiDN-95Yk88?t=173)
4. Закэшированный меш идёт рывками (топология меняется каждый кадр) → удали кэш меша, затем **Build Cache ▸ Continue** — частицы воспроизводятся с ретаймом, а мешер кэшируется уже из них. [▶ 4:12](https://youtu.be/SiDN-95Yk88?t=252)
5. Исправь двойной ретайм: на **теге кэша мешера ▸ Override** воспроизведения, по умолчанию 100 % (реальное время). [▶ 5:36](https://youtu.be/SiDN-95Yk88?t=336)
6. Тот же workflow работает и для ретаймленных шлейфов.

## Как сейчас (новые инструменты)
