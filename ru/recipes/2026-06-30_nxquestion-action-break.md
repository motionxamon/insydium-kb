# Запуск/остановка зацикленной анимации nxQuestion через action Break

- Источник: Top Tip Tuesday — Action Break — https://www.youtube.com/watch?v=CqeOLYEiaKg (2026-06-30)
- Хост / поколение: NeXus (C4D; в Blender так же) — nxQuestion, nxColor (distance), nxAttract/nxPush
- Задача: частицы бесконечно пульсируют размером (вопрос с синусоидой), но останавливаются по требованию — через какое-то время, на нужном размере или пока рядом объект.

## Исходный цикл
nxQuestion: **If Math ▸ Wave > 0 → Set Radius 70 cm** (вариация, Delay + Damping для пружинистости) / **Else → Set Radius 2**. Wave со временем ходит в пределах −100…100 → бесконечная пульсация.

## Как остановить
1. **Break должен стоять первым в стеке** (наверху списка вопросов), иначе вопрос с волной отработает раньше, чем дело дойдёт до break.
2. Остановка через время: `If Age > 150 → Action Break`.
3. Остановка в нужном состоянии: сделай Break дочерним для второго вопроса с оператором **AND**: `Age > 150 AND Radius < 5 (±3)` → замереть маленькими; или `Radius > 60 (±10)` → замереть большими.
4. Остановка, пока рядом объект (интерактивно): слой **nxColor** *Distance from Object* (подключи Null, чёрный→белый на ~1000 cm). Затем наверху `If Color Brightness < 0.2 → Break`. Break действует, только пока вопрос выполняется → уведи null подальше, и цикл продолжится. Добавь `AND Radius < 5`, чтобы частицы сначала уменьшились, а потом замерли.

## Заметки
- Break пропускает оставшиеся вопросы для этой частицы на этом кадре — это покадровый шлагбаум, а не постоянное состояние.
- Применение: медицинские/клеточные анимации, реагирующие на зонд.
