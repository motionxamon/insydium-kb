# Рампа замедления на мешированной жидкости (ретайм кэша частиц, затем кэш мешера из ретаймленных частиц)

- Источник: Top Tip Tuesday — Retime Cached Meshes — https://www.youtube.com/watch?v=SiDN-95Yk88 (2024-10-29)
- Хост / поколение: C4D; ретайм в **xpCache** + CPU xpOpenVDBMesher
- Задача: плавное слоу-мо на одном всплеске — и для частиц, и для меша.

## Шаги
1. xpCache ▸ Playback ▸ Retiming **Time (seconds)**: ключ 0 s на кадре 0 и 500/30 = **16.6 s** на последнем кадре; кривая **Linear**.
2. Добавь два ключа вокруг всплеска, выдели оба, сдвинь вправо → пологий участок = слоу-мо.
3. Частицы плавно интерполируются **только при фиксированном числе частиц** (все рождены на кадре 0); динамически порождённую пену заполнить промежуточными позициями нельзя.
4. Закэшированный меш идёт рывками (топология меняется каждый кадр) → удали кэш меша, затем **Build Cache ▸ Continue** — частицы воспроизводятся с ретаймом, а мешер кэшируется уже из них.
5. Исправь двойной ретайм: на **теге кэша мешера ▸ Override** воспроизведения, по умолчанию 100 % (реальное время).
6. Тот же workflow работает и для ретаймленных шлейфов.

## Как сейчас (новые инструменты)
Меширование ретаймленного кэша через nxMesher (GPU) в Fused 2025.4+.
