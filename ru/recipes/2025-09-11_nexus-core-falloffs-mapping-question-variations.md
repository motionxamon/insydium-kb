# Обзор функций: переписанное GPU-ядро NeXus, GPU falloffs + Data Mapping на каждом слое, вариации в nxQuestion и поиск соседей

- Источник: Fused 2025 Tech Preview — Core Improvements — https://www.youtube.com/watch?v=7tXR_Fpk6mw (2025-09-11)
- Хост / поколение: C4D; NeXus (nx…) на xpEmitters (G2) — превью перед **Fused 2025.4** (вышел в декабре 2025)
- Задача: показать, что дают новое GPU-ядро и общие инструменты управления NeXus.

## Переписанное ядро
- Ядро упростили и переписали: симуляции быстрее, VRAM меньше. Тайминги из демо (старое ядро → новое): жидкость + nxVorticity + nxRotate + много камней с коллизиями, 501 F: **75 s → 60 s**; nxTurbulence + nxRotate + nxColor при 150,000 p/s, 501 F: **32 s → 26 s**; SPH granular + переключение групп через nxQuestion + 2 коллайдера: **66 s → 56 s**.
- Больше нет разовой паузы при первом проигрывании (старое ядро в этот момент компилировало GPU compute shaders; у нативных частиц C4D похожий подвис при первом запуске).

## Слоёные модификаторы + GPU falloffs (демо: nxScale, nxColor)
- Стек слоёв **Set Value** в **nxScale**: базовый слой (радиус ~3 + вариация) → слой «noise» (15 cm) → слой «sphere» (~28 cm). Верхние слои в режиме смешивания **Normal** игнорируют то, что под ними; переключите их на **Max**, чтобы база работала как минимальный размер.
- У каждого слоя своя **вкладка Falloffs** (в отличие от C4D Fields, которые считаются на CPU и навешиваются на объект): falloff **Noise** на GPU-шумах INSYDIUM (например, Cubic), falloff **Sphere** (размер/смещение), который можно двигать вживую.
- **nxColor**: два слоя **Gradient by Parameter** (синий и оранжевый, оба по Radius); верхний маскируем Noise falloff — зажмите шум в чёрно-белый для чётких пятен, поднимите частоту, чтобы анимация шла быстрее.

## Data Mapping на каждом слое
- Вкладка Mapping ▸ карта **Age** ▸ выберите **слой** и его параметр (например, «Radius Value» noise-слоя). Диапазон 0–30 F = рост от 0 до полного размера.
- Новые **режимы clamp** (взяты из Range-слоёв), в том числе **Cycle**: кривая подъёма и спада на ~40–60 F повторяется → пульсирующий радиус; задайте второму слою другой диапазон (например, 20–60), чтобы сдвинуть пульсации.

## nxQuestion
- **Вариация на actions** (Set Radius 70 cm + вариация; Set Color с RGB-вариацией ~0.1) и **на questions** (например, Age > 50 с вариацией 50 → рост вразнобой). Низкий **Weight** у action = плавное смешивание вместо резкого скачка.
- Категория **Document ▸ Time > 120** → **Add Speed** (~70, вариация ~30) = фейковая гравитация; Speed > 150 → Set Color (низкий weight → плавный переход) + **Set Display** (Planes Filled) + безусловный **Add Rotation** с вариацией → вращающиеся плоскости.
- **Поиск соседей с фильтром по emitter**: question 1 Particle ▸ Emitter = Fox; AND question 2 **Neighbors**, считающий только частицы Fox, **< 18–20** → частицы на поверхности. Action **Set Group** «fluid» — nxFluids + nxGravity действуют только на эту группу, и оболочка слезает кадр за кадром (таяние). Добавьте третью AND-проверку соседей по emitter-у «stream» (count > 5 в радиусе 20 cm), чтобы таяли только поверхностные частицы, которых коснулся поток, — поток управляет эрозией.

## Как сейчас (новые инструменты)
Всё вошло в Fused 2025.4; бета NeXus 2026.1 расширяет falloffs до 16 режимов и добавляет **nxFalloff Modifier** (Remap, Step, Freeze, Decay…), а Mapping может управлять множеством целей с одного слоя.
