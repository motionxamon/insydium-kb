# Пульсация скорости / размера частиц через nxQuestion Math ▸ Wave

- Источник: Top Tip Tuesday — Sine Wave Action — https://www.youtube.com/watch?v=XiexaAsk03g (2026-05-19)
- Хост / поколение: NeXus (nxQuestion, curl nxTurbulence, nxPush, nxAttract) — C4D и Blender
- Задача: повторяющаяся анимация вкл/выкл любого свойства частиц (скорость, радиус, цвет).

## Как работает Wave
Math ▸ **Wave** = синус от **−100 до +100**, X = жизнь частицы или время документа; один цикл в секунду при Frequency 1 (2 = быстрее, 0.5 = 2 s на цикл). При рождении 0, растёт до 100, спускается до −100 и возвращается.

## Пульсация скорости (трейлы)
- Curl nxTurbulence (только направление) + трейлы.
- `If Wave > 0 → Set Speed 68–100` / `Else → Set Speed 0`.
- **Weight** действия **< 100%** (~45%) → плавный разгон/торможение вместо резкого скачка; меньший вес у действия остановки = более долгое торможение.
- Вариация на Set Speed; **вариация на сравнении Wave** (например, ±30) → частицы выходят из синхрона.

## Пульсация размера (shot статичных сфер)
- Радиус эмиттера 0; `If Wave (freq 0.5) > 0 → Set Radius 59 ±53` / `Else → Set Radius 2–3`, веса < 100%.
- **nxPush** (режим Particle Radius, полная сила) *под* вопросом → выросшие сферы расталкивают друг друга; **nxAttract** стягивает их обратно, когда они маленькие.
- **Delay + Damping** на Set Radius → пружинистый перелёт.
