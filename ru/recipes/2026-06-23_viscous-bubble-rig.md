# Пузыри внутри вязкой FLIP-жидкости (поиск соседей)

- Источник: Top Tip Tuesday — Viscous Bubble Rig — https://www.youtube.com/watch?v=fP-g5fC1PHs (2026-06-23)
- Хост / поколение: C4D, Fused 2025.4+ (nxFluids FLIP, поиск соседей в nxQuestion, nxMesher, nxScale) + Redshift
- Задача: из тех же частиц жидкости выбрать случайный набор, который рендерится как пузыри и никогда не выходит на поверхность.

## Сетап
1. Вкладка Groups эмиттера: создайте **две группы** (дважды Ctrl-клик по Create Group), режим **First Group Only** → все частицы стартуют в группе 1 (мёд); группа 2 = пузыри.
2. nxQuestion:
   - `If Math ▸ Random (Time Variation: None, 0–20000) < 400` (у каждой частицы своё фиксированное число → случайная выборка; на тестах поднимите до 6000)
   - **AND** `Particle ▸ Neighbors (radius 10 cm) > 400` → только частицы глубоко внутри (у поверхностных соседей меньше)
     - Действия: Set Color жёлтый (для отладки) + **Set Group → Group 2**
   - `Else → Set Group → Group 1` (если пузырь всплыл к поверхности, он снова становится жидкостью)
3. Мешим только мёд: **nxMesher** (группа 1). Пузыри: **Redshift Object tag** на эмиттере → Particles → sphere instances, Groups = группа 2, материал пузыря.
4. Размеры пузырей: **nxScale**, Groups Affected = группа 2, слой **Set Value** (clamp выключен), радиус 0.5 с большой вариацией.
5. Количество пузырей регулируйте порогом Random.

## Заметки
- Подгоните радиус поиска соседей под масштаб сцены (здесь зона поиска ≈ сфера 10 cm) и порог количества, пока жёлтые частицы перестанут касаться поверхности.
- Для поиска соседей в сцене нужен nxFluids.
