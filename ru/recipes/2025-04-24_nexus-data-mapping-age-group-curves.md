# Как читать кривую Data Mapping: радиус по возрасту и по группе (nxScale ▸ Mapping)

- Источник: Bite-Sized — NeXus Data Mapping — https://www.youtube.com/watch?v=AMCR5ciL7fw (2025-04-24)
- Хост / поколение: C4D; xpEmitter + NeXus GPU nxScale (вкладка Mapping работает так же в других nx-модификаторах/динамике и в X-Particles)
- Задача: разобраться, где диапазон (X), а где множитель параметра (Y), — на примере роста частиц с возрастом и размера по группам.

## Исходная сцена
xpEmitter **Shot ▸ Hexagonal**, статичные частицы; три xpGroup, вкладка Groups эмиттера использует все три в режиме **Random** (цвет показывает группу).

## Шаги
1. **nxScale** ▸ Object: **Set Value**, Radius **60 cm**. [▶ 1:12](https://youtu.be/AMCR5ciL7fw?t=72)
2. Mapping ▸ добавьте слой **Age**; Parameter = **Radius Value** (Map To автоматически Age). [▶ 2:21](https://youtu.be/AMCR5ciL7fw?t=141)
3. Чтение графика: **ось X = диапазон** (Range Min 0 F → X 0, Range Max 30 F → X 1); **ось Y = множитель заданного значения** (Y 0 → 0 cm, Y 1 → 60 cm). После максимального возраста частицы остаются 60 cm. [▶ 2:30](https://youtu.be/AMCR5ciL7fw?t=150)
4. Range Max **100** → рост медленнее. ПКМ ▸ Spline Presets ▸ **Linear**, Ctrl-клик — узел на X 0.5 / Y 0.5 → в возрасте 50 кадров радиус 30 cm. [▶ 5:05](https://youtu.be/AMCR5ciL7fw?t=305)
5. Пресет Cubic = медленный старт, потом быстрый рост; перевёрнутая кривая = рождаются полного размера и уменьшаются до 0 к 100 F. [▶ 6:42](https://youtu.be/AMCR5ciL7fw?t=402)
6. По группам: удалите слой Age, добавьте слой **Group**, тот же параметр. **Range Min 1, Range Max 3** (группы 0 здесь нет) → group 1 на X 0, group 2 на X 0.5, group 3 на X 1. [▶ 8:01](https://youtu.be/AMCR5ciL7fw?t=481)
7. Группы — целые числа, поэтому важны только значения узлов ровно в этих точках X; форма кривой между ними ни на что не влияет. Например Y 0 / 0.5 / 1 → 0 / 30 / 60 cm; двигайте узлы, чтобы задать размер каждой группы. [▶ 10:40](https://youtu.be/AMCR5ciL7fw?t=640)

## Как сейчас (новые инструменты)
В Fused 2025.4 появился Data Mapping с looping; в NeXus 2026.1 один слой Mapping управляет многими целями, а у каждого слоя модификатора есть свой список falloff.
