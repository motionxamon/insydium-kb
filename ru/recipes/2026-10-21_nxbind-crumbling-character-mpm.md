# Идущий персонаж рассыпается в песок (nxBind + отрыв по фоллоффу + nxMPM brittle)

- Источник: NeXus Official Training — nxBIND — https://www.youtube.com/watch?v=-QzOnmifveY (2026-10-21)
- Хост / поколение: Blender (NeXus for Blender, 2026.1 beta); nxEmitter, nxBind, nxKill, nxFalloff, nxMPM, nxGravity
- Задача: частицы заполняют анимированного Alembic-зомби, повторяют его походку, затем отрываются кусками начиная с головы и ссыпаются в кучу рассыпчатого песка.

## Исходная сцена
Низкополигональный, чисто ремешенный персонаж с минимумом самопересечений (складки под коленями дают шальные частицы).

## Шаги
1. **nxEmitter**: Shape Object (зомби), эмиссия из **Volume**, режим сетки **Hexagonal**, Shot, скорость 0. В режиме hexagonal радиус задаёт количество (0.01 → ~13k частиц для тестов). [▶ 1:40](https://youtu.be/-QzOnmifveY?t=100)
2. Модификатор **nxBind**: Object = тот же зомби, настройки по умолчанию → частицы едут вместе с деформирующимся объёмом. [▶ 3:01](https://youtu.be/-QzOnmifveY?t=181)
3. Чистка шальных частиц: **nxKill**, Volume = Object (зомби), переключите иконку inside/outside, чтобы он убивал частицы **снаружи**. После первых кадров (~кадр 52) поставьте ключ **Enabled** off, чтобы потом не убивать оторвавшиеся частицы. [▶ 4:12](https://youtu.be/-QzOnmifveY?t=252)
4. nxBind ▸ вкладка **Break** — отрыв по Falloff (по умолчанию; без фоллоффа ничего не отрывается), Particle Age (например, 60→150 кадров) или Color Brightness (рисуйте расползающийся цвет). **Chunks** on; **Chunk Size** ~0.3 для крупных кусков; выключите **Soften**, когда подхватывает жидкостный солвер (чёткое «привязан/оторван»). [▶ 6:36](https://youtu.be/-QzOnmifveY?t=396)
5. Отрыв сверху вниз: Break = Falloff; добавьте **Linear falloff** по **+Z**, небольшой, над головой; анимируйте его Z ключами вниз до ступней (ступни оставьте привязанными, чтобы они пинали обломки). [▶ 8:55](https://youtu.be/-QzOnmifveY?t=535)
6. **nxMPM** с доменом (необязательно — sparse, — но домен даёт более точный контроль и быстрее считается). Display ▸ Draw Grid (Back), чтобы видеть воксели. [▶ 10:23](https://youtu.be/-QzOnmifveY?t=623)
7. Эмиттер ▸ **Match Solver Resolution** → nxMPM; радиус теперь задаётся солвером. Resolution 40 → ~600 частиц; **150** → ~30k (для демо, не для продакшена). [▶ 11:50](https://youtu.be/-QzOnmifveY?t=710)
8. **nxGravity**. Материал MPM Liquid → пресет **Brittle** (**Concrete**) для рассыпчатого песка. Считается дольше (зато точнее). [▶ 12:35](https://youtu.be/-QzOnmifveY?t=755)
9. Объект MPM ▸ низ: добавьте **Wall Friction**, чтобы обломки перестали скользить. [▶ 13:15](https://youtu.be/-QzOnmifveY?t=795)
10. Display эмиттера: градиент по **Granular**, Auto Scale off, максимум ~20, чтобы читались куски. [▶ 13:30](https://youtu.be/-QzOnmifveY?t=810)

## Подводные камни
- Перекрывающаяся/внутренняя геометрия ломает проверку inside/outside — сначала ремеш.
- Не оставляйте kill снаружи объёма включённым, когда частицы начинают отрываться.

## Как сейчас (новые инструменты)
Это и есть самый новый путь (2026.1 beta). В legacy CPU прямого аналога не было (трюки в духе xpSticky/xpCover); nxPin — родственный инструмент, когда частицы нужно закрепить, а не нести внутри объёма.
