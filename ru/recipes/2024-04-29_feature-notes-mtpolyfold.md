# Обзор функций: процедурное складывание и отслаивание mtPolyFold (MeshTools 2024.2)

- Источник: MeshTools Sneak Peek — Procedural Folding & Peeling Effects, Release Update Coming Soon — https://www.youtube.com/watch?v=EDxcs1zAXvQ (2024-04-29)
- Хост / поколение: C4D; MeshTools (процедурное моделирование, без частиц)
- Статус: превью **Fused 2024.2** (9 мая 2024); раньше было доступно в открытой бете INSYDIUM Fused (регистрация через аккаунт клиента)

## Что делает
Любой дочерний объект разбивается на полосы, которые складываются/отслаиваются от **fold points**; анимация складывания даёт разворачивание или отслаивание.

## Ключевые параметры
- Fold points: **Random** (количество точек, seed), из **texture tag/shader** (noise + слайдер **Tolerance** для количества точек; перевёрнутый градиент выбирает только нижние полигоны = аккуратное отслаивание от основания) или режим **Selection** с тегом выделения полигонов.
- **Fold Angle** (анимируйте для разворачивания); **variation** добавляет смещение между полосами.
- **Angle Limit** соседних полигонов: низкий = минимум складывания, выше = захватывается больше соседних полигонов.
- Направление: **Center** или **Clockwise** (интересно на круглых/сферических объектах); количество точек 1 = весь меш разворачивается одной полосой.
- **Remove** — удаление сложенных полигонов для wipe-on/off, время задаётся **Remove Offset**.
- Сочетается с остальными MeshTools (например, mtShellGen для толщины).
