# Направление эмиссии с объектов: Normal, Phong Normal и Random Blend (режимы направления xpEmitter)

- Источник: Bite-Sized — Emission Direction — https://www.youtube.com/watch?v=90Qk_MPNZbg (2025-05-29)
- Хост / поколение: C4D; xpEmitter (настройки эмиссии с объекта, работают для CPU и оранжевых GPU-эмиттеров)
- Задача: управлять тем, летят ли частицы ровными струями по нормалям полигонов, плавно эмитятся с лоу-поли геометрии или расходятся вокруг нормали.

## Шаги
1. **xpEmitter ▸ Object**: форма Object, подключите примитив-сферу. По умолчанию эмиссия идёт из **Polygon Center** с направлением **Normal** → по одной струе на полигон. [▶ 0:26](https://youtu.be/90Qk_MPNZbg?t=26)
2. **Polygon Area** тоже следует нормали каждой грани → между гранёными направлениями видны просветы. [▶ 0:50](https://youtu.be/90Qk_MPNZbg?t=50)
3. Для плавной эмиссии с лоу-поли геометрии: оставьте на объекте **Phong tag** и выставьте направление **Phong Normal**. Угол Phong 0 = снова гранёно; чем больше угол, тем мягче и шейдинг, и эмиссия. [▶ 1:46](https://youtu.be/90Qk_MPNZbg?t=106)
4. Разброс вокруг нормали (демо на плоскости, Polygon Center): направление должно быть **Normal**. Обычный **Random** полностью теряет струи. [▶ 3:53](https://youtu.be/90Qk_MPNZbg?t=233)
5. Раскройте стрелку у направления, чтобы увидеть кривую **Random Blend**. Удалите один узел, чтобы получилась ровная линия; 0 = чистая нормаль, малое значение = небольшой конус разброса вокруг каждой струи, **0.5 = разброс 180°**, **1 = то же, что Random**. [▶ 4:22](https://youtu.be/90Qk_MPNZbg?t=262)

## Подводные камни
- Random Blend есть только в режиме Normal.
- Phong Normal зависит от угла Phong tag, а не от разрешения меша.
